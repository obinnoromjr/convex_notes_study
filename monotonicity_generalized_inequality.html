§0where we are

Two notions, one lift

§3.6 takes two scalar notions — monotonicity and convexity — and lifts them from the ordinary order on \(\mathbf{R}\) to a generalized inequality \(\preceq_K\) associated with a proper cone \(K\). Both lifts follow the same recipe: keep the definition's shape, replace \(\le\) by \(\preceq_K\) wherever a vector comparison is being made.

This subsection handles monotonicity only. Here the lift is one-sided: the hypothesis \(x \preceq_K y\) becomes a cone inequality, while the conclusion \(f(x)\le f(y)\) stays an ordinary scalar inequality, because \(f\) is still real-valued. (Lifting the conclusion too is what §3.6.2 does, with \(K\)-convexity.)

→

What to walk away with. One formula: \(f\) is \(K\)-nondecreasing \(\iff \nabla f(x)\in K^{*}\). Everything else on this page is either the definition that makes that statement sayable, or an example that makes it checkable.

§1definitions

\(K\)-nondecreasing and \(K\)-increasing

Let \(K\subseteq\mathbf{R}^{n}\) be a proper cone with associated generalized inequality \(\preceq_K\). A function \(f:\mathbf{R}^{n}\to\mathbf{R}\) is called \(K\)-nondecreasing if \[ x \preceq_K y \;\Longrightarrow\; f(x)\le f(y), \] and \(K\)-increasing if \[ x \preceq_K y,\; x\ne y \;\Longrightarrow\; f(x) < f(y). \] B&V §3.6.1 · L5582–5589

The mirror notions are defined by reversing the value inequality: \(f\) is \(K\)-nonincreasing if \(x\preceq_K y \Rightarrow f(x)\ge f(y)\), and \(K\)-decreasing if \(x\preceq_K y,\, x\ne y \Rightarrow f(x) > f(y)\). Equivalently, \(f\) is \(K\)-nonincreasing exactly when \(-f\) is \(K\)-nondecreasing, so every result below has a free mirror image.

When \(n=1\) and \(K=\mathbf{R}_+\), the generalized inequality \(\preceq_K\) is the ordinary \(\le\), and the two definitions collapse to the ordinary notions of a nondecreasing and an increasing function on \(\mathbf{R}\). That degenerate case is the sanity check to run whenever a statement below looks unfamiliar.

  • shape
    The hypothesis is a partial order; the conclusion is a total one. \(\preceq_K\) compares only some pairs, so the definition constrains \(f\) only on comparable pairs.
  • slack
    Because \(\preceq_K\) is partial, \(K\)-nondecreasing is a weaker demand than it looks. Two points that are \(K\)-incomparable — \(x\not\preceq_K y\) and \(y\not\preceq_K x\) — impose no constraint at all, and \(f\) may do anything between them.
  • strict
    \(K\)-increasing demands strict growth along every nonzero cone direction, including the ones on the boundary of \(K\) — that boundary is exactly where the strict version usually fails.
!

Bigger cone, stronger condition. Enlarging \(K\) makes \(\preceq_K\) compare more pairs, so it makes \(K\)-nondecreasing harder to satisfy. The dual side moves the other way — \(K\) larger means \(K^{*}\) smaller — which is exactly why the gradient condition of §4 is stated with \(K^{*}\).

§2example 3.45

Monotone vector functions — the nonnegative orthant

Example 3.45 (monotone vector functions). A function \(f:\mathbf{R}^{n}\to\mathbf{R}\) is nondecreasing with respect to \(K=\mathbf{R}^{n}_{+}\) if and only if \[ x_1\le y_1,\;\; x_2\le y_2,\;\ldots,\;\; x_n\le y_n \;\Longrightarrow\; f(x)\le f(y) \] for all \(x,y\). This is equivalent to saying \(f\) is nondecreasing in each component \(x_i\), with the other components \(x_j\) (\(j\ne i\)) held constant. B&V §3.6.1 · L5591–5598

The first display is just \(\preceq_{\mathbf{R}^{n}_{+}}\) written out componentwise: \(y-x\in\mathbf{R}^{n}_{+}\) means every coordinate of \(y\) is at least the corresponding coordinate of \(x\). The content of the example is the second sentence — that this global-looking condition reduces to \(n\) separate one-variable conditions.

Why the reduction works, both ways. (⟸) Suppose \(f\) is nondecreasing in each component separately, and \(x\preceq y\) componentwise. Walk from \(x\) to \(y\) one coordinate at a time: \(x=z^{0}\to z^{1}\to\cdots\to z^{n}=y\), where \(z^{i}\) agrees with \(y\) in the first \(i\) coordinates and with \(x\) in the rest. Each step changes exactly one coordinate, and changes it upward, so \(f(z^{i-1})\le f(z^{i})\); chaining gives \(f(x)\le f(y)\). (⟹) Conversely, moving a single coordinate upward is a special case of \(x\preceq y\), so componentwise monotonicity is immediate.

!

The chain is the whole argument. It works because \(\mathbf{R}^{n}_{+}\) is generated by the coordinate vectors \(e_1,\dots,e_n\): any \(y-x\in\mathbf{R}^{n}_{+}\) decomposes as a nonnegative combination of them. A cone with a different set of extreme rays gets a different "walk one generator at a time" statement — which is precisely what the dual-cone condition of §4 generalizes.

§3example 3.46

Matrix monotone functions — the PSD cone

Example 3.46 (matrix monotone functions). A function \(f:\mathbf{S}^{n}\to\mathbf{R}\) is called matrix monotone (increasing, decreasing) if it is monotone with respect to the positive semidefinite cone \(\mathbf{S}^{n}_{+}\). Some examples, with \(X\in\mathbf{S}^{n}\): B&V §3.6.1 · L5601–5614
functionbehaviour w.r.t. \(\mathbf{S}^{n}_{+}\)domain
\(\mathbf{tr}(WX)\)matrix nondecreasing iff \(W\succeq0\); increasing iff \(W\succ0\)\(\mathbf{S}^{n}\)
\(\mathbf{tr}(WX)\)matrix nonincreasing iff \(W\preceq0\); decreasing iff \(W\prec0\)\(\mathbf{S}^{n}\)
\(\mathbf{tr}(X^{-1})\)matrix decreasing\(\mathbf{S}^{n}_{++}\)
\(\det X\)matrix increasing\(\mathbf{S}^{n}_{++}\)
\(\det X\)matrix nondecreasing\(\mathbf{S}^{n}_{+}\)

Read \(\mathbf{tr}(WX)\) as the inner product \(\langle W,X\rangle\) on \(\mathbf{S}^{n}\). Then the first two rows say something that should feel familiar: a linear functional \(\langle W,\cdot\rangle\) is \(K\)-nondecreasing exactly when \(W\) lies in the dual cone — and \(\mathbf{S}^{n}_{+}\) is self-dual, so "\(W\in(\mathbf{S}^{n}_{+})^{*}\)" reads simply as \(W\succeq0\). The "iff" is genuine in both directions, and the strict versions match the strict cone conditions.

The last three rows are nonlinear, and they carry a sign trap worth naming: on \(\mathbf{S}^{n}_{++}\), moving up in the PSD order makes \(\mathbf{tr}(X^{-1})\) go down while \(\det X\) goes up. Both quantities measure "size" in some loose sense, yet they move in opposite directions, because the inverse reverses the order (\(0\prec X\preceq Y \Rightarrow Y^{-1}\preceq X^{-1}\)) and the determinant does not. Note also the domain distinction on \(\det\): increasing only on the interior \(\mathbf{S}^{n}_{++}\), merely nondecreasing on all of \(\mathbf{S}^{n}_{+}\) — on the boundary a singular \(X\) has \(\det X=0\) and a nonzero PSD step can leave it at \(0\).

The step direction slider is doing real work. Because \(v v^{T}\) is rank one, \(\frac{d}{dt}\mathbf{tr}(WX(t))=\mathbf{tr}(W vv^{T})=v^{T}Wv\) — the sign of the whole trace curve is decided by a quadratic form in \(v\). With \(W=I\) it is \(\|v\|^{2}>0\) for every \(\varphi\): matrix increasing. With \(W=\mathrm{diag}(1,0)\succeq0\) it is \(\cos^{2}\varphi\ge0\), which vanishes at \(\varphi=90^{\circ}\): nondecreasing but not increasing, exactly matching the "iff \(W\succ0\)" in the table. With the indefinite \(\mathrm{diag}(1,-1)\) it is \(\cos2\varphi\), whose sign flips — so no monotonicity of any kind. The other two curves never care about \(W\): \(\frac{d}{dt}\mathbf{tr}(X^{-1})=-\|X^{-1}v\|^{2}<0\) and \(\frac{d}{dt}\det X=\det(X)\,v^{T}X^{-1}v>0\) for every \(\varphi\), which is the analytic content of rows three and four.

!

Matrix monotone is not "monotone entrywise", and not "monotone in the eigenvalues" either. \(X\mapsto X^{2}\) is not matrix nondecreasing on \(\mathbf{S}^{n}_{+}\) even though \(t\mapsto t^{2}\) is nondecreasing on \(\mathbf{R}_{+}\) — scalar monotonicity does not transfer to matrix arguments. The gradient test of §4 is what tells you which functions do transfer.

§4the key result

The gradient condition — nonnegative in the dual

Start from the scalar fact everyone already owns.

A differentiable function \(f:\mathbf{R}\to\mathbf{R}\), with convex domain, is nondecreasing if and only if \(f'(x)\ge0\) for all \(x\in\mathbf{dom}\,f\). B&V §3.6.1 · L5619–5623

Now lift it. The naive guess would be "\(\nabla f(x)\in K\)". That guess is wrong, and the correction is the single most important line on this page.

Suppose \(f\) is differentiable with convex domain. Then \(f\) is \(K\)-nondecreasing if and only if \[ \nabla f(x)\succeq_{K^{*}}0 \quad\text{for all } x\in\mathbf{dom}\,f, \tag{3.24} \] i.e. the gradient lies in the dual cone \(K^{*}\) at every point of the domain. B&V §3.6.1 · L5626–5636 · eq. (3.24)
!

The gradient must be nonnegative in the dual inequality. Not \(\nabla f(x)\succeq_K 0\) — \(\nabla f(x)\succeq_{K^{*}}0\). The reason is structural: \(K^{*}=\{z : z^{T}u\ge0 \text{ for all } u\in K\}\) is by definition the set of vectors that pair nonnegatively with every cone direction, and "pair nonnegatively with every cone direction" is exactly what a gradient must do for \(f\) to increase along every \(K\)-step. The condition is the dual cone's defining property, not a coincidence.

The strict version: if \[ \nabla f(x)\succ_{K^{*}}0 \quad\text{for all } x\in\mathbf{dom}\,f, \tag{3.25} \] then \(f\) is \(K\)-increasing. As in the scalar case, the converse is false. B&V §3.6.1 · L5638–5643 · eq. (3.25)

The asymmetry between (3.24) and (3.25) is inherited verbatim from \(n=1\): \(f'(x)\ge0\) everywhere characterizes nondecreasing, but \(f'(x)>0\) everywhere is only sufficient for increasing. The standard witness is \(f(x)=x^{3}\), which is increasing on \(\mathbf{R}\) even though \(f'(0)=0\). Nothing about the cone repairs this; the failure is already there in one dimension.

Claim — \(f\) is \(K\)-nondecreasing \(\iff\) \(\nabla f(x)\in K^{*}\) on \(\mathbf{dom}\,f\)why the dual cone
\[ x\preceq_K y \;\iff\; y-x\in K \]
setup — translate the order into cone membership. The step vector \(u=y-x\) ranges over exactly \(K\).
\[ f(y)-f(x)=\int_{0}^{1}\nabla f\big(x+s\,u\big)^{T}u\,ds \]
sufficiency — the fundamental theorem along the segment (legitimate because \(\mathbf{dom}\,f\) is convex). Every integrand is \(\nabla f(\cdot)^{T}u\) with \(u\in K\), so \(\nabla f\in K^{*}\) makes each one \(\ge0\), hence \(f(y)\ge f(x)\).
\[ \nabla f(z)\notin K^{*} \;\Rightarrow\; \exists\, v\in K:\; \nabla f(z)^{T}v < 0 \]
necessity, step 1 — this is the definition of \(K^{*}\), read contrapositively. Failing to be in the dual cone means failing against some concrete cone direction \(v\): the witness comes for free.
\[ h(t)=f(z+tv),\qquad h'(0)=\nabla f(z)^{T}v<0 \]
necessity, step 2 — restrict \(f\) to the ray through \(z\) in direction \(v\). Its derivative at \(0\) is strictly negative.
\[ f(z+tv)<f(z)\ \text{ for small } t>0,\qquad z\preceq_K z+tv \]
conclusion — the pair \((z,\,z+tv)\) is \(K\)-ordered (since \(tv\in K\)) yet the value drops. So \(f\) is not \(K\)-nondecreasing. ∎

Two hypotheses earn their place in that proof. Differentiability is what lets the value change be written as an integral of directional derivatives — drop it and the characterization becomes a statement about subgradients instead. Convexity of \(\mathbf{dom}\,f\) is what guarantees the segment from \(x\) to \(y\) stays in the domain, so the integral is even defined; on a disconnected domain a pointwise gradient condition says nothing about comparisons across the gap.

Two readings of the same picture. Push the half-angle below \(45^\circ\) and \(K^{*}\) becomes strictly larger than \(K\): there are gradients outside the cone that still certify monotonicity, because a narrow cone asks \(f\) to increase along few directions. Push it above \(45^\circ\) and \(K^{*}\) shrinks inside \(K\): a wide cone demands a lot, and admissible gradients are scarce. Only at exactly \(45^\circ\) — the orthant, up to rotation — do the two sets coincide.

!

Self-duality is what hides the distinction. The two cones you meet most often, \(\mathbf{R}^{n}_{+}\) and \(\mathbf{S}^{n}_{+}\), are self-dual: \(K^{*}=K\). Every worked example in §2 and §3 therefore satisfies (3.24) with the gradient in \(K\) itself, and the dual never announces itself. Reach for a non-self-dual cone — a narrow or wide simplicial cone, or the second-order cone under a non-orthogonal change of coordinates — and writing \(K\) where (3.24) says \(K^{*}\) gives a flatly wrong answer.

Reconciling §2, §3 and (3.24)

Vector case. For \(K=\mathbf{R}^{n}_{+}\), self-duality gives \(K^{*}=\mathbf{R}^{n}_{+}\), so (3.24) reads \(\nabla f(x)\succeq 0\), i.e. \(\partial f/\partial x_i\ge0\) for every \(i\) — which is precisely "nondecreasing in each component" from Example 3.45. The chain-of-coordinates argument and the gradient condition are the same statement, one discrete and one infinitesimal.

Matrix case. For \(K=\mathbf{S}^{n}_{+}\), again \(K^{*}=K\), and the gradients are exactly what Example 3.46 needs:

  • trace
    \(f(X)=\mathbf{tr}(WX)\) has \(\nabla f(X)=W\). So (3.24) reads \(W\succeq0\) — matching the table's "iff", and \(W\succ0\) gives the increasing case via (3.25).
  • inverse
    \(f(X)=\mathbf{tr}(X^{-1})\) has \(\nabla f(X)=-X^{-2}\prec0\) on \(\mathbf{S}^{n}_{++}\). The gradient is in \(-\mathrm{int}\,K^{*}\), so \(f\) is matrix decreasing.
  • determinant
    \(f(X)=\det X\) has \(\nabla f(X)=\det(X)\,X^{-1}\succ0\) on \(\mathbf{S}^{n}_{++}\), so \(f\) is matrix increasing there. On \(\mathbf{S}^{n}_{+}\) the formula degenerates at singular \(X\) and only the nondecreasing claim survives.
§5expert lens

What to keep straight

01The gradient condition is the point

\(K\)-nondecreasing \(\iff \nabla f(x)\in K^{*}\), the dual cone — not \(K\). If you remember one thing from §3.6.1, remember which cone the gradient lives in.

02Self-dual cones mask it

\(\mathbf{R}^{n}_{+}\) and \(\mathbf{S}^{n}_{+}\) have \(K^{*}=K\), so every familiar example is silent about the distinction. Test your understanding on a cone that is not self-dual.

03Strictness is one-way

(3.25): \(\nabla f\succ_{K^{*}}0 \Rightarrow K\)-increasing. Sufficient, not necessary — \(x^{3}\) already breaks the converse in one dimension.

04Vector case, unpacked

For \(\mathbf{R}^{n}_{+}\): \(\nabla f\in\mathbf{R}^{n}_{+}\) \(\iff\) nondecreasing in each component with the others fixed (Example 3.45).

05Matrix case, unpacked

For \(\mathbf{S}^{n}_{+}\): \(\mathbf{tr}(WX)\) nondecreasing iff \(W\succeq0\); \(\mathbf{tr}(X^{-1})\) decreasing on \(\mathbf{S}^{n}_{++}\) (\(\nabla=-X^{-2}\prec0\)); \(\det X\) increasing on \(\mathbf{S}^{n}_{++}\) (\(\nabla=\det(X)X^{-1}\succ0\)).

06The sign trap

On \(\mathbf{S}^{n}_{++}\), \(\mathbf{tr}(X^{-1})\) is decreasing while \(\det X\) is increasing. Two "size" measures, opposite directions.

07Scope

§3.6.1 is monotonicity only. \(K\)-convexity — lifting the conclusion to a generalized inequality — is a separate construction in §3.6.2.

Summary — main points for quick review

definitions

\(f\) is \(K\)-nondecreasing if \(x\preceq_K y\Rightarrow f(x)\le f(y)\); \(K\)-increasing if the value inequality is strict for \(x\ne y\). Reversing the value inequality gives \(K\)-nonincreasing / \(K\)-decreasing. At \(K=\mathbf{R}_+\), \(n=1\), these are the ordinary notions.

gradient — eq. (3.24)

Differentiable \(f\) with convex domain is \(K\)-nondecreasing \(\iff \nabla f(x)\succeq_{K^{*}}0\) for all \(x\) — the gradient in the dual cone.

strict — eq. (3.25)

\(\nabla f(x)\succ_{K^{*}}0\) for all \(x\) \(\Rightarrow\) \(f\) is \(K\)-increasing. Sufficient, not necessary (\(x^{3}\)).

vector case

\(K=\mathbf{R}^{n}_{+}\), self-dual: \(K\)-nondecreasing \(\iff\) nondecreasing in each component separately.

matrix case

\(K=\mathbf{S}^{n}_{+}\), self-dual: \(\mathbf{tr}(WX)\) nondecreasing iff \(W\succeq0\); \(\mathbf{tr}(X^{-1})\) decreasing on \(\mathbf{S}^{n}_{++}\); \(\det X\) increasing on \(\mathbf{S}^{n}_{++}\), nondecreasing on \(\mathbf{S}^{n}_{+}\).

the trap

Self-dual cones hide the \(K^{*}\) in (3.24). Change to a non-self-dual \(K\) and writing \(K\) for \(K^{*}\) gives the wrong answer.
