Convexity w.r.t. a
generalized inequality

§3.6.1 lifted monotonicity to a cone. This lifts convexity: f : Rⁿ → Rᵐ is K-convex if Jensen's inequality holds in the order ⪯K. The cone now sits in the codomain, and a single dual test — wᵀf convex for every w ⪰K* 0 — decides it.

§0where we are

§3.6 lifts two scalar notions to a generalized inequality ⪯K. §3.6.1 did monotonicity; this does convexity. One structural warning first, because it's the most common confusion here: in §3.6.1 the cone lived in the domain and the gradient landed in the dual cone K*. In §3.6.2 the cone K ⊆ Rᵐ lives in the codomain — it orders the output vectors f(x). The dual cone K* reappears, but only as the set of scalarizing weights in the dual characterization (§5). Keep the two K's in their correct spaces.

§1definition
For a proper cone K ⊆ Rᵐ, a function f : Rⁿ → Rᵐ is K-convex if for all x, y and 0 ≤ θ ≤ 1, \[ f(\theta x+(1-\theta)y)\ \preceq_K\ \theta f(x)+(1-\theta) f(y). \] It is strictly K-convex if \(f(\theta x+(1-\theta)y)\prec_K \theta f(x)+(1-\theta) f(y)\) for \(x\neq y\), \(0<\theta<1\). B&V §3.6.2 · L5653–5664

Same Jensen form as the scalar case; the only change is ≤ becomes ⪯K. At m = 1, K = R₊ it reduces to ordinary (strict) convexity.

§2example 3.47 — componentwise inequality
For K = Rᵐ₊, f is K-convex iff every component fᵢ is convex (strictly K-convex iff each fᵢ strictly convex).B&V §3.6.2 · L5666–5676

Componentwise K-convexity is just "convex in each output coordinate."

§3example 3.48 — matrix convexity
For f : Rⁿ → Sᵐ with K = Sᵐ₊: f is matrix convex if \(f(\theta x+(1-\theta)y)\preceq \theta f(x)+(1-\theta)f(y)\). Equivalently: f is matrix convex iff the scalar zᵀf(x)z is convex in x for every fixed z (strict iff zᵀf(x)z strictly convex for every z ≠ 0).B&V §3.6.2 · L5679–5698

Examples: f(X) = XXᵀ (X ∈ Rⁿˣᵐ) is matrix convex — for fixed z, zᵀXXᵀz = ‖Xᵀz‖₂², a convex quadratic in X. Same reason: f(X) = X² is matrix convex on Sⁿ. Xᵖ is matrix convex on Sⁿ₊₊ for 1 ≤ p ≤ 2 or −1 ≤ p ≤ 0, matrix concave for 0 ≤ p ≤ 1. f(X) = exp(X) (matrix exponential) is not matrix convex on Sⁿ for n ≥ 2 — scalar convexity of eᵗ does not lift to the matrix order.

!

The matrix test needs every z, not just a convenient one. It is exactly what breaks for exp(X): some directions z give a convex zᵀ exp(X) z, others don't — Lab 1 lets you hunt for the failing z.

§4restriction to a line
As with ordinary convexity, f is K-convex iff its restriction to every line in dom f is K-convex — i.e. g(t) = f(x + t v) is K-convex in t for all x, v.B&V §3.6.2 · L5701–5704

Many questions reduce to a 1-D check — exactly the move Lab 1 uses: parametrize X(t) = X0 + tV, then check the scalar curve.

§5dual characterization — the workhorse
f is K-convex iff for every w ⪰K* 0, the real-valued wᵀf is convex (ordinary sense); strictly K-convex iff for every nonzero w ⪰K* 0, wᵀf is strictly convex.B&V §3.6.2 · L5706–5710

It collapses vector convexity into a family of scalar convexity checks, one per dual-feasible weight w ∈ K*. It follows from a ⪯K b ⟺ wᵀa ≤ wᵀb for all w ⪰K* 0, applied to both sides of Jensen.

!

Matrix convexity is exactly this specialized. For K = Sᵐ₊ (self-dual), the weights are W ⪰ 0 acting by tr(Wf). The rank-one zzᵀ generate Sᵐ₊, and tr(zzᵀf) = zᵀfz — so "tr(Wf) convex for all W ⪰ 0" is "zᵀfz convex for all z," the §3 test.

K = R²₊, so K* = R²₊ too. f is K-convex iff both f1, f2 are convex. §5's dual test says: wᵀf must be convex for every w ⪰ 0 — try a1 < 0 with w1 small to see the combination stay convex, then raise w1 to see it fail.

§6differentiable K-convex — first-order condition
A differentiable f is K-convex iff dom f is convex and, for all x, y ∈ dom f, \[ f(y)\ \succeq_K\ f(x) + Df(x)(y-x), \] where Df(x) ∈ Rᵐˣⁿ is the Jacobian. Strict iff ≻K for x ≠ y.B&V §3.6.2 · L5714–5721

Exact vector analog of f(y) ≥ f(x) + ∇f(x)ᵀ(y−x): the affine approximation underestimates f(y) in the order ⪯K.

§7composition theorem
If g : Rⁿ → Rᵖ is K-convex, h : Rᵖ → R is convex, and the extended-value extension h̃ is K-nondecreasing, then h ∘ g is convex (ordinary sense).B&V §3.6.2 · L5723–5728

This generalizes "a nondecreasing convex function of a convex function is convex" (§3.2.4): h̃ K-nondecreasing pushes the inner ⪯K inequality forward through h without reversing it, and ordinary convexity of h then closes Jensen. The hypothesis forces dom h − K = dom h.

↺

Note the output type-change: g is vector/matrix-valued and K-convex, but h ∘ g is real-valued and ordinarily convex — a bridge from generalized convexity back to scalar convexity.

§8example 3.49 — worked composition

Let A ∈ Sᵐ, B ∈ Rᵐˣⁿ, C ∈ Sⁿ, and g(X) = XᵀAX + BᵀX + XᵀB + C. Then g is matrix convex (Sⁿ₊-convex) when A ⪰ 0. Take h(Y) = −log det(−Y), convex and increasing on dom h = −Sⁿ₊₊. By the composition theorem,

\[ f(X) = -\log\det\!\big(-(X^{\mathsf T}AX+B^{\mathsf T}X+X^{\mathsf T}B+C)\big) \] is convex on {X | XᵀAX + BᵀX + XᵀB + C ≺ 0} when A ⪰ 0.B&V §3.6.2 · L5730–5752

Generalizes the scalar fact that −log(−(ax² + bx + c)) is convex on {x | ax²+bx+c < 0} when a ≥ 0. Lab 3 works exactly this scalar case — it is the n = m = 1 shadow of Example 3.49, and shows both halves: the composition needs h̃ K-nondecreasing (here, ordinary "increasing"), and the inner quadratic needs to stay inside its domain (q(x) < 0).

§9expert lens — diagnose

G1Codomain, not domain

Cone K ⊆ Rᵐ orders the outputs — the §3.6.1 contrast: monotonicity put the gradient in a domain cone's dual; here K* only supplies scalarizing weights.

G2Two concrete tests

Componentwise (Rᵐ₊): each fᵢ convex. Matrix (Sᵐ₊): zᵀf(x)z convex for all z (strict: all z ≠ 0). XXᵀ, X² matrix convex; exp(X) not for n ≥ 2.

G3Dual characterization

The everyday tool: wᵀf convex for every w ⪰K* 0. The matrix test is this with w = zzᵀ.

G4First-order

f(y) ⪰K f(x) + Df(x)(y−x), Jacobian Df.

G5Composition

Delivers ordinary convexity, and needs h̃ K-nondecreasing (not K-convex).

G6Traps

Cone in the codomain not the domain; the matrix test needs every z; exp(X) kills naive "scalar convex ⟹ matrix convex."

Summary · 2026-08-28 · bv.3.6.2

Main points for quick review

Definition

\(f:\mathbb R^n\to\mathbb R^m\) is K-convex if \(f(\theta x+(1-\theta)y)\preceq_K \theta f(x)+(1-\theta)f(y)\) (cone \(K\subseteq\mathbb R^m\) orders outputs); strict with \(\prec_K\). \(m=1,K=\mathbb R_+\) recovers ordinary convexity.

Two concrete tests

Componentwise (\(\mathbb R^m_+\)): ⟺ each \(f_i\) convex. Matrix (\(S^m_+\)): ⟺ \(z^{\mathsf T}f(x)z\) convex for all \(z\); \(XX^{\mathsf T}\), \(X^2\) matrix convex; \(X^p\) convex for \(1\le p\le2\)/\(-1\le p\le0\), concave \(0\le p\le1\); \(\exp(X)\) not matrix convex (\(n\ge2\)).

Dual characterization

⟺ \(w^{\mathsf T}f\) convex for every \(w\succeq_{K^*}0\) (matrix test = this with \(w=zz^{\mathsf T}\)).

First-order

⟺ \(\operatorname{dom}f\) convex and \(f(y)\succeq_K f(x)+Df(x)(y-x)\).

Composition

\(g\) K-convex, \(h\) convex, \(\tilde h\) K-nondecreasing ⟹ \(h\circ g\) ordinarily convex. Ex 3.49: \(f(X)=-\log\det(-(X^{\mathsf T}AX+B^{\mathsf T}X+X^{\mathsf T}B+C))\) convex where the matrix quadratic is \(\prec0\) (needs \(A\succeq0\)).
