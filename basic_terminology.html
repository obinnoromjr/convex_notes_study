Basic
terminology

Pure vocabulary before Chapter 4 gets going: what a standard-form optimization problem is, and exactly what "optimal", "feasible", and "attained" mean. No convexity yet — that's §4.2. Precision here is what the rest of the book leans on.

p⋆ = inf f₀(x) fᵢ(x) ≤ 0 hᵢ(x) = 0 B&V §4.1.1, pp. 127–129 · mastery: diagnose
§0where we are

Chapter 3 built the function-level machinery (convexity, quasiconvexity, log-concavity, K-convexity). Chapter 4 is about problems. §4.1.1 is pure vocabulary: what a standard-form optimization problem is and what its solution concepts precisely mean. Nothing here assumes convexity yet — this is the general optimization problem; convex problems are §4.2. The payoff is precision: the rest of the book leans on these exact definitions.

§1the standard-form problem
minimize \(f_0(x)\)
subject to \(f_i(x)\le 0,\quad i=1,\dots,m\)
        \(h_i(x)=0,\quad i=1,\dots,p\) B&V Eq. (4.1) · L6519–6530

The names: x ∈ Rⁿ the optimization variable; f₀ : Rⁿ → R the objective (or cost) function; fᵢ(x) ≤ 0 the inequality constraints (fᵢ the inequality constraint functions); hᵢ(x) = 0 the equality constraints (hᵢ the equality constraint functions). If m = p = 0, the problem is unconstrained.

§2domain vs feasible set
\[ \mathcal D = \Big(\bigcap_{i=0}^{m}\operatorname{dom}f_i\Big)\cap\Big(\bigcap_{i=1}^{p}\operatorname{dom}h_i\Big) \] the domain — where every objective/constraint function is defined. B&V L6531–6542

A point x ∈ D is feasible if it satisfies all the constraints. The problem is feasible if at least one feasible point exists, infeasible otherwise. The set of all feasible points is the feasible set (or constraint set).

!

Keep them distinct: D only asks the functions be defined; feasibility additionally asks the constraints hold.

§3optimal value and the ±∞ conventions
\[ p^{\star} = \inf\{\, f_0(x)\mid f_i(x)\le 0,\ h_i(x)=0 \,\} \] allowed extended values ±∞. B&V L6543–6551

Two load-bearing conventions:

  • infeasible
    p⋆ = +∞ — the inf of f₀ over the empty set is +∞ by convention.
  • unbounded below
    p⋆ = −∞ — feasible xₖ with f₀(xₖ) → −∞.
!

Note the direction: infeasibility pushes p⋆ up to +∞, not down — a common slip is to think "no solutions" should be −∞.

§4optimal, locally optimal, ε-suboptimal
\(x^{\star}\) is an optimal point (it solves the problem) if it's feasible and \(f_0(x^{\star})=p^{\star}\); the optimal set is \(X_{\text{opt}}=\{\,x \mid \text{feasible},\ f_0(x)=p^{\star}\,\}\).B&V L6553–6580
  • attained
    If an optimal point exists, p⋆ is attained / achieved and the problem is solvable.
  • not attained
    If Xopt = ∅, p⋆ is not attained — always the case when unbounded below, but it can happen with finite p⋆ too (see §6).
A feasible \(x\) is ε-suboptimal (\(\varepsilon>0\)) if \(f_0(x)\le p^{\star}+\varepsilon\).
A feasible \(x\) is locally optimal if there is \(R>0\) such that \(f_0(x)=\inf\{\, f_0(z)\mid f_i(z)\le 0,\ h_i(z)=0,\ \|z-x\|_2\le R \,\}\) — \(x\) beats all nearby feasible points.
↳

"Optimal" means globally optimal throughout B&V. (A central fact of Chapter 4 — that for a convex problem local ⟹ global — is §4.2.2, not yet in scope.)

§5active, inactive, redundant constraints
At a feasible \(x\): the \(i\)th inequality \(f_i(x)\le 0\) is active if \(f_i(x)=0\), inactive if \(f_i(x)<0\); equality constraints are active at every feasible point; a constraint is redundant if deleting it does not change the feasible set.B&V L6581–6584

§6example 4.1 — the optimal value need not be attained

Unconstrained, x ∈ R, dom f₀ = R₊₊:

three variations on R₊₊
f₀(x) = 1/x
p⋆ = 0, not achieved — 1/x → 0 as x → ∞ but never equals it, so no x⋆.
f₀(x) = −log x
p⋆ = −∞, unbounded below.
f₀(x) = x log x
p⋆ = −1/e, achieved at the unique x⋆ = 1/e.
!

Internalize the first case: a finite optimal value with an empty optimal set. inf is not min.

§7feasibility problems

If the objective is identically zero, p⋆ is either 0 (feasible set nonempty) or +∞ (empty). This is the feasibility problem, written

find \(x\) subject to \(f_i(x)\le 0,\ h_i(x)=0\)B&V L6595–6608

It asks whether the constraints are consistent, and if so produces a satisfying point.

§8expert lens — what to keep straight (diagnose)

E1Standard form

Minimize f₀ s.t. fᵢ ≤ 0, hᵢ = 0; m=p=0 ⟹ unconstrained.

E2Domain ≠ feasible set

D = functions defined; feasible set = constraints hold.

E3p⋆ conventions

Infeasible ⟹ +∞ (inf of ∅); unbounded below ⟹ −∞. Infeasibility goes up, not down.

E4Attained vs not

Optimal ⟹ feasible AND f₀(x⋆) = p⋆; Xopt = ∅ ⟹ not attained — always when unbounded below, and possible with finite p⋆ (1/x on R₊₊). inf ≠ min.

E5Local vs global

Local = best within a ball of radius R; "optimal" = global. (Convexity collapses the two — §4.2.2.)

E6Active / inactive / redundant

Active fᵢ(x)=0 / inactive fᵢ(x)<0; equalities active at all feasible points; redundant = removable.

E7Feasibility problem

f₀ ≡ 0; p⋆ ∈ {0, +∞}.

E8Scope

General problem, no convexity yet (that's §4.2); standard-form transformations are §4.1.2–§4.1.3.

Main points for quick review

Standard form

Minimize \(f_0(x)\) s.t. \(f_i(x)\le0\) (\(i{=}1..m\)), \(h_i(x)=0\) (\(i{=}1..p\)); variable \(x\in\mathbf{R}^n\), objective \(f_0\). Unconstrained if \(m=p=0\).

Domain vs feasible set

\(\mathcal D=\bigcap\operatorname{dom}f_i\cap\bigcap\operatorname{dom}h_i\) (functions defined) vs feasible set (constraints hold); feasible iff a feasible point exists.

Optimal value

\(p^\star=\inf\{f_0\mid\text{feasible}\}\), extended \(\pm\infty\): infeasible ⟹ \(+\infty\); unbounded below ⟹ \(-\infty\).

Attainment

Optimal \(x^\star\): feasible with \(f_0(x^\star)=p^\star\); \(X_{\text{opt}}\) the optimal set; attained iff \(X_{\text{opt}}\neq\varnothing\) (\(\inf\neq\min\) — \(1/x\) on \(\mathbf{R}_{++}\) has \(p^\star=0\) unattained). Locally optimal = best within a ball; "optimal" = global.

Constraints & feasibility problems

Active \(f_i(x)=0\) / inactive \(f_i(x)<0\); equalities active at all feasible points; redundant = removable. Feasibility problem: \(f_0\equiv0\), \(p^\star\in\{0,+\infty\}\).
