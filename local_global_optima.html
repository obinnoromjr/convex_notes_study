Local and
global optima

The single most important consequence of convexity: there is no gap between a local optimum and the global one. A method that finds a local optimum has found the global optimum — full stop.

convex feasible set convex f₀ local ⟹ global B&V §4.2.2, pp. 138–139 · mastery target: diagnose
§0where we are

§4.2.1 defined the convex problem and showed its feasible set is convex. This section is the single most important consequence — the property that makes convex optimization tractable: there is no gap between local and global optima. A method that finds a local optimum has found the global one.

§1the theorem (B&V L7088–7089)
A fundamental property of convex optimization problems is that any locally optimal point is also (globally) optimal.B&V §4.2.2 · L7088–7089

Recall (§4.1.1): x is locally optimal if it is feasible and, for some R > 0,

\[ f_0(x) = \inf\{\, f_0(z) \mid z \text{ feasible}, \ \|z-x\|_2 \le R \,\} \qquad (4.19) \]

x beats every feasible point within distance R. The theorem says that for a convex problem this local statement forces the global one: f₀(x) = p⋆.

§2the proof (B&V L7089–7102)

By contradiction. Suppose x is locally optimal (4.19) but not globally optimal — so there is a feasible y with f₀(y) < f₀(x).

Steps 1–4contradiction
\[ \text{Step 1 — } y \text{ must be far: } \|y-x\|_2 \le R \implies f_0(x)\le f_0(y) \]
if ‖y−x‖₂ ≤ R, y is one of the feasible points the infimum (4.19) ranges over, forcing f₀(x) ≤ f₀(y) — contradiction. So ‖y−x‖₂ > R.
\[ \text{Step 2 — } z=(1-\theta)x+\theta y,\quad \theta=\frac{R}{2\|y-x\|_2} \]
since ‖y−x‖₂ > R, θ ∈ (0, 1/2), and ‖z−x‖₂ = θ‖y−x‖₂ = R/2 < R.
\[ \text{Step 3 — } z \text{ is feasible} \]
z is a convex combination of feasible x, y, and the feasible set is convex (§4.2.1), so z is feasible.
\[ \text{Step 4 — } f_0(z) \le (1-\theta)f_0(x)+\theta f_0(y) < f_0(x) \]
by convexity of f₀ (Jensen); strict since θ > 0 and f₀(y) < f₀(x).

z is feasible, within R/2 < R of x, with f₀(z) < f₀(x) — contradicting (4.19). Hence no such y exists; x is globally optimal. ∎

LAB 1

Build the contradiction: drag x, y and the radius R

f₀(t), convex R-neighborhood of x z on segment [x,y]
controls

Drag x (candidate local optimum) and y (a feasible point with lower value) along the curve. Slide R. If y is outside the R-band, the proof builds z on the segment, strictly closer than R and strictly better than x — a genuine contradiction. Pull y inside the band and the contradiction dissolves: x wasn't really locally optimal there to begin with.

§3which assumption does what

The proof uses both convexity ingredients, each load-bearing:

  • set
    Convexity of the feasible set — Step 3, so the constructed z on [x,y] is feasible.
  • f₀
    Convexity of f₀ — Step 4, so Jensen gives the strict decrease.

Remove either and it collapses: nonconvex feasible set ⟹ z need not be feasible; merely quasiconvex f₀ ⟹ Step 4 fails.

LAB 2

Does z stay feasible? Toggle the feasible set's shape

feasible set segment [x,y]
controls

Drag x and y, both feasible. z slides along the segment via θ. With the convex disk, every z on [x,y] stays feasible — Step 3 always holds. Switch to the nonconvex (dumbbell) set and drag x, y into the two lobes: the segment now cuts through the gap, so z falls outside the feasible set — Step 3 breaks, and the whole argument stalls right there.

§4it fails for quasiconvex problems (B&V L7122–7123)
It is not true that locally optimal points of quasiconvex problems are globally optimal (see §4.2.5).B&V §4.2.2 · L7122–7123

The step that breaks is Step 4: quasiconvexity gives only

\[ f_0(z) \le \max\{f_0(x), f_0(y)\} = f_0(x) \]

(a ≤, not the strict < the contradiction needs). Convexity (Jensen's averaging), not mere quasiconvexity (the max-bound), is what powers the theorem.

LAB 3

Convex vs. quasiconvex: does the chord still beat max{f₀(x), f₀(y)}?

f₀(t) Jensen chord max{f(x), f(y)}
controls

Drag x and y; slide θ to move z along the segment. For convex f₀, the curve never rises above the chord, so f₀(z) ≤ chord < max{f(x),f(y)} whenever f(y) < f(x) — a genuine strict drop. Switch to quasiconvex (not convex) f₀: the curve can bulge above its own chord (watch the gap at the kink), so all quasiconvexity still guarantees is f₀(z) ≤ max{f(x),f(y)} — equality is possible, and the contradiction in §2 no longer fires.

§5expert lens — what to keep straight (diagnose)

E1Theorem

Convex problem ⟹ every local optimum is global. No strict convexity, no unconstrained assumption.

E2Proof shape

Contradiction — better far-away y ⟹ slide to nearby feasible z = (1−θ)x + θy, θ = R/(2‖y−x‖₂), ‖z−x‖₂ = R/2 < R; z feasible (convex set), f₀(z) < f₀(x) (convex f₀, Jensen).

E3Both ingredients matter

Convex feasible set ⟹ z feasible; convex f₀ ⟹ strict decrease. A convex feasible set alone is not enough.

E4Quasiconvex fails

Jensen degrades to f₀(z) ≤ max{f₀(x),f₀(y)} = f₀(x) — only ≤.

E5Why it matters

Local search finds the global optimum — the root of convex optimization's tractability.

Main Points for Quick Review

Theorem

For a convex optimization problem, any locally optimal point is globally optimal (\(f_0(x)=p^\star\)). No strict convexity or unconstrained assumption needed.

Proof (contradiction)

If local-opt \(x\) is not global, a feasible \(y\) has \(f_0(y)R\); the segment point \(z=(1-\theta)x+\theta y\), \(\theta=R/(2\|y-x\|_2)\), has \(\|z-x\|_2=R/2

Both convexities used

Feasible-set convexity ⟹ \(z\) feasible; \(f_0\) convexity ⟹ strict decrease (Jensen).

Quasiconvex caveat

FAILS for quasiconvex \(f_0\) — Jensen degrades to \(f_0(z)\le\max\{f_0(x),f_0(y)\}=f_0(x)\) (only \(\le\)), so a quasiconvex local optimum need not be global (§4.2.5).
