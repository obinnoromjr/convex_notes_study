§0where we are

§4.1.1–§4.1.2 fixed the standard form and its conventions. This section is the toolbox of equivalence transformations — ways to rewrite a problem into a different but equivalent one. It's used constantly later, in modeling and in reformulating a problem into a solvable form. Still the general problem: equivalence here does not require convexity (that's §4.2).

Equivalence (informal). Two problems are equivalent if from a solution of one, a solution of the other is readily found, and vice versa. B&V §4.1.3 · L6662–6680

Note what this does not claim: the two problems need not share the same feasible set, variable space, or even optimal value — only a readily-recoverable solution correspondence. Each transformation below states its own correspondence: some (scaling, function transformation) keep the same optimizers; others (slack variables, the epigraph form, equality elimination) relate solutions across different variable spaces.

Σ

Scaling example. \(f_0\to\alpha_0 f_0\), \(f_i\to\alpha_i f_i\) (\(\alpha_i>0\)), and \(h_i\to\beta_i h_i\) (\(\beta_i\ne0\)) leaves the feasible set and the optimal points unchanged — only the optimal value scales, by \(\alpha_0\). Equivalent, not the same problem.

§1change of variables
Let \(\phi:\mathbf R^n\to\mathbf R^n\) be one-to-one, with image covering the domain \(\mathcal D\). Define \(\tilde f_i(z)=f_i(\phi(z))\), \(\tilde h_i(z)=h_i(\phi(z))\). Then \(\text{minimize }\tilde f_0(z)\) subject to \(\tilde f_i(z)\le0,\ \tilde h_i(z)=0\) is equivalent to the original problem, via \(x=\phi(z)\). B&V L6682–6694

The correspondence is direct: x solves the original problem if and only if z = φ⁻¹(x) solves the transformed one. Every function is just precomposed with the reparametrization; nothing about the constraints or objective changes in substance, only the coordinates they're written in.

§2transformation of objective and constraint functions
Suppose \(\psi_0\) is monotone increasing, \(\psi_i(u)\le0 \iff u\le0\) for \(i=1,\dots,m\), and \(\psi_{m+i}(u)=0\iff u=0\) for \(i=1,\dots,p\). Composing, \(\tilde f_i=\psi_i(f_i(x))\), \(\tilde h_i=\psi_{m+i}(h_i(x))\) gives an equivalent problem — with identical feasible sets and optimal points. B&V L6698–6714

Unlike slack variables or the epigraph form below, this move keeps the same variable x and the same feasible set — the scaling example in §0 is the linear special case (\(\psi_0(u)=\alpha_0 u\), etc.).

Example 4.3 — least-norm
(4.5)
\(\text{minimize } \|Ax-b\|_2\)
(4.6)
\(\text{minimize } \|Ax-b\|_2^2\)
via
\(\psi_0(u)=u^2\), increasing on \(u\ge0\) — so (4.5) ⟺ (4.6), same optimizers.
but
(4.5) is not differentiable wherever \(Ax-b=0\); (4.6) is a quadratic, hence differentiable everywhere.
!

The recurring lesson: an equivalence can trade one nice property (a familiar norm) for another (differentiability) — same solutions, different analytical convenience.

§3slack variables
\(f_i(x)\le0 \iff \exists\, s_i\ge0\) with \(f_i(x)+s_i=0\). B&V L6731–6753

Problem (4.7):

minimize \(f_0(x)\)
subject to \(s_i\ge0,\ i=1,\dots,m\)
        \(f_i(x)+s_i=0,\ i=1,\dots,m\)
        \(h_i(x)=0,\ i=1,\dots,p\)
variables \(x\in\mathbf R^n,\ s\in\mathbf R^m\). B&V L6731–6753

Counts: n + m variables, m inequality constraints (the bounds sᵢ ≥ 0), and m + p equality constraints. Each original inequality becomes one equality plus one nonnegativity. Equivalent via sᵢ = −fᵢ(x).

!

The equality count is m + p, not just p — the m slack-defining equations count too.

§4eliminating equality constraints

If every solution of hᵢ(x) = 0 (i=1,…,p) can be parametrized as x = φ(z) for z ∈ Rᵏ, the equalities can be removed entirely:

minimize \(f_0(\phi(z))\) subject to \(f_i(\phi(z))\le0,\ i=1,\dots,m\), variable \(z\), no equality constraints. B&V L6755–6769

z optimal for this problem implies x = φ(z) is optimal for the original. The equality constraints haven't been solved away by accident — they've been folded into the parametrization of the feasible set.

§5eliminating linear equality constraints

The linear case Ax = b makes §4 concrete. If b ∉ R(A), the problem is infeasible. Otherwise, let x₀ be any particular solution and let F satisfy R(F) = N(A) — the general solution is x = Fz + x₀, and taking F full rank gives k = n − rank A.

minimize \(f_0(Fz+x_0)\) subject to \(f_i(Fz+x_0)\le0,\ i=1,\dots,m\) — no equality constraints, and \(\text{rank}\,A\) fewer variables. B&V L6771–6783
!

Elimination drops exactly rank A variables — not p (the number of equality constraints), which can exceed rank A if some equalities are redundant.

§6introducing equality constraints

The reverse move: add new variables yᵢ = Aᵢx + bᵢ to split apart compositions with affine maps. The problem

minimize \(f_0(A_0x+b_0)\) subject to \(f_i(A_ix+b_i)\le0,\ h_i(x)=0\) B&V L6785–6815

becomes

minimize \(f_0(y_0)\) subject to \(f_i(y_i)\le0,\ y_i=A_ix+b_i,\ h_i(x)=0\) B&V L6785–6815

This adds Σkᵢ variables and Σkᵢ equality constraints (one block per introduced yᵢ). The payoff: the objective and the inequality constraint functions now act on separate variables, so they become independent of each other rather than sharing x through a composition.

§7optimizing over some variables
\(\displaystyle\inf_{x,y} f(x,y) = \inf_x \tilde f(x)\), where \(\tilde f(x)=\inf_y f(x,y)\). B&V L6817–6864

For a problem (4.9) whose constraints split independently between x₁ and x₂, minimizing over x₂ first gives

\(\tilde f_0(x_1)=\inf\{\,f_0(x_1,z)\mid \tilde f_i(z)\le0\,\}\) B&V L6817–6864

— an equivalent problem (4.10) in x₁ alone. This is the problem-level face of the §3.2.5 partial-minimization rule.

§8epigraph problem form

Problem (4.11):

minimize \(t\) subject to \(f_0(x)-t\le0,\ f_i(x)\le0,\ h_i(x)=0\), variables \(x,t\). B&V L6867–6882

(x,t) is optimal for (4.11) if and only if x is optimal for the original problem (4.1) and t = f₀(x). The objective is now linear in (x,t) — all the nonlinearity has migrated into the constraint f₀(x) − t ≤ 0.

Geometrically: minimize t over epi f₀ subject to the constraints — the lowest point in the epigraph (Fig 4.1).

↓

The epigraph trick is why linear-objective reformulations are so common in solvers: any problem can be rewritten with a linear cost, at the price of one new variable and one new constraint.

§9implicit and explicit constraints

Make explicit → implicit (4.12): define F = f₀ on dom F = the feasible set (and ∞ off it). Then

minimize \(F(x)\) — unconstrained, and equivalent. B&V L6884–6955

This is a notational trick: the constraints are hidden inside dom F, and F is likely not differentiable, since its domain is likely not open.

Make implicit → explicit (4.13 → 4.14): the function f(x) = xᵀx for Ax = b, ∞ otherwise, hides an implicit equality constraint Ax = b inside its domain. Exposing it gives

minimize \(x^{\mathsf T}x\) subject to \(Ax=b\) — constrained, but differentiable. B&V L6884–6955
!

Same trade-off as Example 4.3: hiding constraints buys an unconstrained-looking problem at the cost of differentiability; exposing them buys differentiability at the cost of explicit constraints.

§10expert lens — what to keep straight (diagnose)

E1Equivalence, precisely

A solution of one problem readily yields a solution of the other — not identity, and not necessarily the same feasible set or variable space.

E2Function transformation

ψ₀ must be increasing; the ψᵢ must be sign-preserving. Scaling is the linear special case; ‖·‖₂ ⟺ ‖·‖₂² is ψ₀ = (·)².

E3Slack variables

fᵢ ≤ 0 → fᵢ + sᵢ = 0, sᵢ ≥ 0: n+m variables, m inequalities, m+p equalities.

E4Eliminating equality

Linear case: x = Fz + x₀, drops rank A variables (not p); b ∉ R(A) means infeasible.

E5Optimizing over some variables

inf_{x,y} = inf_x inf_y; Example 4.4 gives the Schur complement P₁₁ − P₁₂P₂₂⁻¹P₁₂ᵀ.

E6Epigraph

Minimize t (linear objective); (x,t) optimal iff x optimal and t = f₀(x).

E7Traps

Equivalent ≠ identical — some moves keep the same optimizers (scaling, function transformation), while lifted/reduced forms (slack, epigraph, elimination) only give a recoverable correspondence across different variable spaces. Slack has m+p equalities, not p. The epigraph objective is t, not f₀. Elimination drops rank A variables, not p.

E8Scope

General problem — no convexity here (that's §4.2); parameter/oracle descriptions are §4.1.4.

Summary · 2026-09-01 · bv.4.1.3 · Equivalent problems (B&V §4.1.3)

Main points for quick review

Equivalence

A solution of one readily gives a solution of the other — not identity; whether feasible sets, optimizers, or value are literally the same depends on the transformation (scaling keeps optimizers and scales the value; slack/epigraph/elimination relate solutions across different variable spaces).

Transformations

Change of variables (\(x=\phi(z)\)); function transformation (\(\psi_0\) increasing; \(\|\cdot\|_2\iff\|\cdot\|_2^2\)); slack (\(f_i+s_i=0,\ s_i\ge0\); \(n{+}m\) vars, \(m\) ineq, \(m{+}p\) eq); eliminate equality (linear \(x=Fz+x_0\), drops rank A vars); introduce equality (\(y_i=A_ix+b_i\)); optimize over some variables (Ex 4.4 Schur complement \(P_{11}-P_{12}P_{22}^{-1}P_{12}^{\mathsf T}\)).

Epigraph form

Minimize \(t\) subject to \(f_0(x)-t\le0\) plus the constraints — objective becomes linear; \((x,t)\) optimal iff \(x\) optimal and \(t=f_0(x)\).

Implicit/explicit

Hide constraints in \(\text{dom}\,F\) (unconstrained, \(F\) likely not differentiable) vs. expose them (constrained, differentiable) — a notational trade.
