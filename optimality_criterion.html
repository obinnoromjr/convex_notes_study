§0where we are

§4.2.2 showed local ⟹ global for convex problems, but gave no test for optimality. When f₀ is differentiable, this section gives one: a first-order condition on ∇f₀(x) that is both necessary and sufficient. It specializes to familiar conditions (∇f₀=0 unconstrained, Lagrange multipliers for equality constraints, complementarity for sign constraints), previewing the Chapter 5 treatment of Lagrange multipliers and complementarity.

§1the criterion (B&V (4.20)–(4.21), L7128–7143)

Since f₀ is differentiable and convex, the first-order condition (§3.1.3) holds:

\[ f_0(y) \ge f_0(x) + \nabla f_0(x)^T(y-x) \qquad (4.20) \]B&V (4.20)

With feasible set \(X = \{\, x \mid f_i(x)\le 0,\ h_i(x)=0 \,\}\):

\[ x \text{ is optimal} \iff x\in X \text{ and } \nabla f_0(x)^T(y-x)\ge 0 \ \ \forall\, y\in X \qquad (4.21) \]B&V (4.21)
!

It's ≥ 0, not = 0 — and it has to hold for every feasible y, not just one.

Geometry. If ∇f₀(x) ≠ 0, −∇f₀(x) defines a supporting hyperplane to X at x: no feasible direction is a first-order descent direction (Figure 4.2). The hero above draws exactly this — X sits entirely on the side where ∇f₀(x)ᵀ(y−x) ≥ 0, so −∇f₀(x) points strictly away from the set.

§2proof (B&V L7145–7162)
(⟸)criterion ⟹ optimal
\[ x\in X \text{ satisfies (4.21)} \implies f_0(y) \ge f_0(x)+\nabla f_0(x)^T(y-x) \ge f_0(x) \]
for any feasible y, (4.20) gives the first inequality; (4.21) gives the second. So x beats every feasible y — optimal.
(⟹)optimal ⟹ criterion, by contradiction
\[ \text{suppose } x \text{ optimal but some } y\in X \text{ has } \nabla f_0(x)^T(y-x)<0 \]
assume (4.21) fails for this y — aiming for a contradiction.
\[ z(t) = ty+(1-t)x,\qquad z(t) \text{ feasible for } t\in[0,1] \]
convex feasible set: a segment between two feasible points stays feasible.
\[ \left.\frac{d}{dt}f_0(z(t))\right|_{t=0} = \nabla f_0(x)^T(y-x) < 0 \]
chain rule at t=0. The derivative is exactly the quantity assumed negative.
\[ \implies f_0(z(t)) < f_0(x) \text{ for small } t>0 \]
negative derivative at 0 means the function is strictly decreasing just past t=0 — contradicts x optimal.
!

Uses convex f₀ (for 4.20) and convex feasible set (for z(t) feasible) — both load-bearing, exactly as in the local/global proof of §4.2.2.

§3unconstrained problems (B&V L7166–7187)

m = p = 0: (4.21) reduces to

\[ \nabla f_0(x) = 0 \qquad (4.22) \]B&V (4.22)

Why: take \(y = x - t\nabla f_0(x)\) (feasible, since dom f₀ is open); then

\[ \nabla f_0(x)^T(y-x) = -t\|\nabla f_0(x)\|_2^2 \ge 0 \]

forces ∇f₀(x) = 0 — the only way a negative-or-zero quantity like −t‖∇f₀(x)‖₂² can be ≥ 0 for t>0 is if the norm itself is zero. No solution ⟹ no optimum (unbounded below, or finite but unattained); multiple solutions ⟹ each is a minimizer.

Example 4.5 · quadratic minimization

f₀ = ½xᵀPx + qᵀx + r, P ⪰ 0. Optimality is Px + q = 0:

  • q ∉ R(P)
    unbounded below — no x solves Px=−q, and moving along the direction that makes Px+q shrink drives f₀ → −∞.
  • P ≻ 0
    unique minimizer x⋆ = −P⁻¹q.
  • P singular, q ∈ R(P)
    an affine set of minimizers Xopt = −P†q + N(P) (P† the pseudo-inverse).

Example 4.6 · analytic centering

f₀ = −Σ log(bᵢ − aᵢᵀx), dom = {Ax ≺ b}. Optimality: ∇f₀(x) = Σ aᵢ/(bᵢ − aᵢᵀx) = 0. Unique minimizer iff {Ax ≺ b} is nonempty and bounded (no solution ⟺ unbounded below; many solutions ⟹ an affine set).

§4equality constraints only — the Lagrange condition (B&V L7242–7270)

min f₀ s.t. Ax = b. Every feasible y is y = x+v for some v ∈ N(A), so optimality (4.21) says

\[ \nabla f_0(x)^Tv \ge 0 \qquad \forall\, v\in N(A) \]
!

N(A) is a subspace — closed under negation, so both v and −v are feasible directions. A ≥ 0 that has to hold for both forces = 0.

\[ \nabla f_0(x)^Tv = 0 \quad \forall\, v\in N(A), \qquad\text{i.e. } \nabla f_0(x)\perp N(A) \]

Since \(N(A)^\perp = R(A^T)\), there is ν with

\[ \nabla f_0(x) + A^T\nu = 0 \quad (\text{with } Ax=b) \]the classical Lagrange multiplier condition (Chapter 5)
§5minimization over the nonnegative orthant — complementarity (B&V L7272–7300)

min f₀ s.t. x ⪰ 0. ∇f₀(x)ᵀy is unbounded below on {y ⪰ 0} unless ∇f₀(x) ⪰ 0; then the condition reduces to ∇f₀(x)ᵀx = 0, and since it's a sum of nonnegative products equal to zero, each term vanishes:

\[ x\succeq 0,\qquad \nabla f_0(x)\succeq 0,\qquad x_i\,(\nabla f_0(x))_i = 0 \]complementarity (Chapter 5)

Sparsity patterns of x and ∇f₀(x) are complementary — wherever one is nonzero, the other must be zero.

!

Complementarity is termwise zero (xᵢ(∇f₀)ᵢ=0 for every i), not merely the aggregate ∇f₀(x)ᵀx=0 — though the two are equivalent precisely because every term is nonnegative.

§6expert lens — what to keep straight (diagnose)

E1Criterion

(4.21): x optimal ⟺ x∈X and ∇f₀(x)ᵀ(y−x)≥0 for all y∈X. It's ≥0 (not =0), over all feasible y.

E2Geometry

−∇f₀(x) supports X at x.

E3Proof

⟸ from (4.20); ⟹ from the segment z(t) and d/dt f₀|₀ = ∇f₀(x)ᵀ(y−x) < 0.

E4Specializations

Unconstrained ∇f₀=0; equality-only ∇f₀+Aᵀν=0 (Lagrange); orthant xᵢ(∇f₀)ᵢ=0 (complementarity).

E5Traps

≥0 over all y, not ∇f₀=0 (only in the unconstrained case); on a subspace, ≥0 forces =0 (both v and −v are feasible directions); complementarity is termwise zero, not just ∇f₀ᵀx=0.

E6Scope

f₀ differentiable throughout; Lagrange and complementarity here preview the Chapter 5 optimality conditions.

Main Points for Quick Review

Criterion (4.21)

\(x\) optimal \(\iff\) \(x\in X\) and \(\nabla f_0(x)^T(y-x)\ge 0\) for all feasible \(y\); geometrically \(-\nabla f_0(x)\) supports \(X\) at \(x\).

Proof

\(\Leftarrow\) from \(f_0(y)\ge f_0(x)+\nabla f_0(x)^T(y-x)\); \(\Rightarrow\) from \(z(t)=ty+(1-t)x\) feasible with \(\left.\frac{d}{dt}f_0\right|_0=\nabla f_0(x)^T(y-x)<0\).

Unconstrained

\(\nabla f_0=0\). Ex 4.5 \(Px+q=0\) (unbounded / unique \(-P^{-1}q\) / affine \(-P^{\dagger}q+N(P)\)).

Equality & orthant

Equality only: \(\nabla f_0+A^T\nu=0\) (Lagrange). Orthant: \(x\succeq 0,\ \nabla f_0\succeq 0,\ x_i(\nabla f_0)_i=0\) (complementarity). Both foreshadow Chapter 5.
