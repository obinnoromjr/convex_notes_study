Representation via a family of convex functions

A quasiconvex \(f\) has convex sublevel sets — so each one can be written as the \(0\)-sublevel set of some convex \(\varphi_t\). The family \(\varphi_t\) is the device that turns a quasiconvex problem into a sequence of convex ones.

§0where we are

From convex sublevel sets to convex functions

§3.4.1 established the defining fact about a quasiconvex function: its sublevel sets are convex. That is a statement about sets. This subsection converts it into a statement about functions — it expresses each sublevel set of \(f\) as the \(0\)-sublevel set of a convex function \(\varphi_t\), one for each level \(t\). Nothing new is being assumed; the content of §3.4.5 is a change of representation, from a family of convex sets to a family of convex functions.

The payoff is computational and comes later. A convex sublevel set is a fine geometric object but not something a solver accepts as input; a convex inequality \(\varphi_t(x)\le 0\) is. This is the device that lets a quasiconvex problem be solved by a sequence of convex feasibility subproblems — bisection on \(t\), §4.2.5.

§1the representation

The family \(\varphi_t\) and equation (3.23)

If \(f\) is quasiconvex, we seek a family of convex functions \(\varphi_t:\mathbf{R}^n\to\mathbf{R}\), indexed by \(t\in\mathbf{R}\), with \[ f(x)\;\le\; t \quad\Longleftrightarrow\quad \varphi_t(x)\;\le\; 0. \tag{3.23} \] That is, the \(t\)-sublevel set of \(f\) is the \(0\)-sublevel set of \(\varphi_t\). B&V §3.4.5 · L5300–5306

Read (3.23) as an identity between two sets, holding for every \(t\):

\[ S_t \;=\; \{\,x \mid f(x)\le t\,\} \;=\; \{\,x \mid \varphi_t(x)\le 0\,\}. \]

The left set is a sublevel set of the possibly-nasty function \(f\); the right set is a sublevel set of a convex function, and is therefore convex. So (3.23) is only possible for functions whose sublevel sets are convex — which is exactly the quasiconvex ones. The representation and the definition of quasiconvexity are consistent by construction; §3.4.5 asks whether the family can actually be produced, and what it looks like.

  • indexing
    One \(\varphi_t\) per level \(t\). The subscript is an index, not an argument being minimised over — \(\varphi_t(\cdot)\) is a function of \(x\) alone, for each fixed \(t\).
  • convexity
    Convexity is demanded in \(x\), separately for each \(t\). Nothing is assumed about joint behaviour in \((x,t)\).
  • direction
    The equivalence runs \(f\le t \Leftrightarrow \varphi_t\le 0\). The threshold on \(f\) is the moving one; the threshold on \(\varphi_t\) is pinned at zero. All the \(t\)-dependence has been pushed into the function.
!

The move is to trade a varying level on a fixed function for a fixed level on a varying function. Sublevel sets of \(f\) at many heights become zero-sublevel sets of many convex functions — and a zero-sublevel set of a convex function is precisely a convex constraint.

§2required vs sufficient

Nesting is the requirement; nonincreasing in \(t\) is one way to get it

The sublevel sets of any function are nested: raising the level can only enlarge the set. For \(s\ge t\),

\[ \{x \mid f(x)\le t\}\;\subseteq\;\{x \mid f(x)\le s\}. \]

Under the representation (3.23) this becomes a condition the family \(\varphi_t\) must satisfy.

The family \(\varphi_t\) must satisfy the nesting property: for all \(x\) and all \(s\ge t\), \[ \varphi_t(x)\le 0 \;\Longrightarrow\; \varphi_s(x)\le 0. \] This holds if for each \(x\), \(\varphi_t(x)\) is a nonincreasing function of \(t\), i.e. \(\varphi_s(x)\le\varphi_t(x)\) for \(s\ge t\). B&V §3.4.5 · L5307–5309
!

Keep the two statuses straight. The implication \(\varphi_t(x)\le 0\Rightarrow\varphi_s(x)\le 0\) is required — it is forced by the nesting of \(f\)'s sublevel sets, so any valid family has it. Pointwise nonincreasing in \(t\) is a sufficient condition for that implication, offered because it is easy to check. It is not the requirement, and it is not necessary.

The logic is one line: if \(\varphi_s(x)\le\varphi_t(x)\) whenever \(s\ge t\), then \(\varphi_t(x)\le 0\) forces \(\varphi_s(x)\le\varphi_t(x)\le 0\). The converse fails — the implication constrains only the sign of \(\varphi_t(x)\) as \(t\) grows, and says nothing about its magnitude. A family whose values wander up and down in \(t\), so long as they cross zero once and stay non-positive after, represents the same nested sets perfectly well.

a family that nests but is not monotone\(f(x)=|x|\) on \(\mathbf{R}\)

Take \(\varphi_t(x)=(2+\sin t)\,(|x|-t)\). For each fixed \(t\), the factor \(2+\sin t\in[1,3]\) is a positive constant and \(|x|-t\) is convex in \(x\), so \(\varphi_t\) is convex. Its sign matches that of \(|x|-t\), so

\[ \varphi_t(x)\le 0 \iff |x|\le t \iff f(x)\le t, \]

and (3.23) holds; the sets \([-t,t]\) nest, so the required implication holds. But \(t\mapsto\varphi_t(x_0)\) is not nonincreasing: its derivative is \(\cos t\,(|x_0|-t)-(2+\sin t)\), which is positive whenever \(|x_0|\) is large and \(t\) is small — e.g. at \(x_0=4,\ t=0.2\) it equals \(\cos(0.2)(3.8)-(2+\sin 0.2)\approx +1.52\). Nesting survives; monotonicity does not.

§3existence & non-uniqueness

A representation always exists — and is never the only one

A representation always exists. We can take \[ \varphi_t(x)=\begin{cases}0 & f(x)\le t\\ \infty & \text{otherwise,}\end{cases} \] i.e. \(\varphi_t\) is the indicator function of \(\{x\mid f(x)\le t\}\). Evidently \(\varphi_t\) is convex for each \(t\), satisfies (3.23), and is nonincreasing in \(t\). B&V §3.4.5 · L5310–5318

Each claim is immediate, but worth saying out loud because the argument is where quasiconvexity is actually spent:

  • convex
    The indicator of a set is convex exactly when the set is convex — and \(\{f\le t\}\) is convex because \(f\) is quasiconvex. This is the one place the hypothesis is used.
  • (3.23)
    \(\varphi_t(x)\le 0\) means \(\varphi_t(x)=0\) (the only finite value it takes), which means \(f(x)\le t\). The equivalence is by definition.
  • nonincreasing
    As \(t\) grows the set \(\{f\le t\}\) grows, so \(\varphi_t(x)\) can only fall from \(\infty\) to \(0\), never rise. The sufficient condition of §2 holds.
§

Existence is therefore free — but the indicator family is useless for computation: it takes the value \(\infty\), it is nondifferentiable everywhere on the boundary, and the constraint \(\varphi_t(x)\le 0\) simply re-states "\(x\) is in the set" without giving a solver anything to work with. It settles the question of existence and nothing more.

The representation by convex functions is not unique. For example, if the sublevel sets of \(f\) are closed, we can take \[ \varphi_t(x)=\operatorname{dist}\big(x,\ \{z\mid f(z)\le t\}\big) = \inf\{\|x-z\|_2 \mid f(z)\le t\}. \] We are usually interested in a family \(\varphi_t\) with nice properties, such as differentiability. B&V §3.4.5 · L5319–5322

The distance function to a convex set is convex, it is zero precisely on the set (hence \(\le 0\) precisely on the set — it is never negative), and it decreases in \(t\) as the target set grows. The closedness hypothesis is what makes the infimum attained and the zero set exactly \(\{f\le t\}\) rather than its closure. So we have two representations of the same family of sets, with wildly different numerical behaviour: one takes values in \(\{0,\infty\}\), the other is finite, continuous, and grows like the distance you would have to travel to become feasible.

three families, one set\(f(x)=\|x\|_\infty\) on \(\mathbf{R}^2\)

The sublevel set \(\{\|x\|_\infty\le t\}\) is the square \([-t,t]^2\). Three convex families cut out exactly that square as their \(0\)-sublevel set:

family\(\varphi_t(x)\)value at \(x=(3,1),\ t=2\)
indicator0 if ‖x‖∞ ≤ t, else ∞∞
distance‖(|x| − t)+‖21.000
norm-shift‖x‖∞ − t1.000

All three are convex in \(x\), all three are nonincreasing in \(t\), and all three declare \(x=(3,1)\) infeasible at \(t=2\) and feasible at \(t=3\). They agree on every sign and disagree on almost every value — the representation pins down the sets, not the numbers. (At \(x=(3,3),\ t=2\) the distance family gives \(\sqrt{1^2+1^2}=1.414\) while the norm-shift gives \(1\): different magnitudes, same sign.)

!

Because the family is not unique, choosing it is a design decision. Prefer one that is finite-valued, smooth, and cheap to evaluate — ideally one for which \(\varphi_t(x)\le 0\) is a constraint your solver already understands. The next section gives the case where such a family drops out for free.

§4example 3.38

Convex over concave

Example 3.38 · Convex over concave function. Suppose \(p\) is convex, \(q\) is concave, with \(p(x)\ge 0\) and \(q(x)>0\) on a convex set \(C\). Then the ratio \(f(x)=p(x)/q(x)\) is quasiconvex on \(C\). B&V §3.4.5 · L5325–5331
Claim: \(f=p/q\) is quasiconvex on \(C\)exhibit a convex family
\[ f(x)\le t \iff \frac{p(x)}{q(x)}\le t \]
start from the sublevel condition, \(t\ge 0\) (for \(t<0\) the set is empty, since \(p\ge0,\ q>0\) give \(f\ge 0\))
\[ \iff p(x)-t\,q(x)\le 0 \]
why \(q(x)>0\) on \(C\), so multiplying through by \(q(x)\) preserves the inequality. This is where the strict positivity of \(q\) is used — not merely \(q\ne 0\), but \(q>0\), so the direction of \(\le\) is kept
\[ \varphi_t(x)\;=\;p(x)-t\,q(x) \]
read off the family: for \(t\ge 0\), \(-t\,q\) is a nonnegative multiple of the convex function \(-q\), so \(\varphi_t\) is a sum of two convex functions — convex
\[ \frac{\partial}{\partial t}\varphi_t(x)\;=\;-q(x)\;<\;0 \]
and \(\varphi_t(x)\) is decreasing in \(t\) — affine in \(t\) with negative slope — so the sufficient condition of §2 holds and the sets nest
\[ \{f\le t\}=\{\varphi_t\le 0\}\ \text{convex}\ \forall t \implies f \text{ quasiconvex} \]
conclude every sublevel set is a \(0\)-sublevel set of a convex function, hence convex
!

The restriction \(t\ge 0\) is load-bearing. For \(t<0\), \(-t\,q=|t|\,q\) is a positive multiple of a concave function, so \(p-tq\) is convex plus concave — no conclusion. Nothing is lost: \(f=p/q\ge 0\) on \(C\), so the sublevel sets for \(t<0\) are empty and need no representation. State the family as "\(\varphi_t=p-tq\) for \(t\ge 0\)".

Note also what the example does not claim. It gives quasiconvexity, not convexity: a ratio of a convex function over a concave one is generally not convex. And the family it produces is the good kind — finite, as smooth as \(p\) and \(q\) are, affine in \(t\), and often (when \(p\) is quadratic and \(q\) affine) a constraint a solver recognises on sight.

§5expert lens · diagnose

What to own from §3.4.5

01 The representation (3.23)

For quasiconvex \(f\), a family of convex \(\varphi_t\) with \(f(x)\le t\iff\varphi_t(x)\le 0\) — the \(t\)-sublevel set of \(f\) is the \(0\)-sublevel set of \(\varphi_t\).

02 Required vs sufficient

The nesting implication \(\varphi_t(x)\le0\Rightarrow\varphi_s(x)\le0\) for \(s\ge t\) is required. Pointwise nonincreasing in \(t\) is a sufficient condition for it — not the requirement, and not necessary.

03 Existence and uniqueness

A representation always exists — the indicator of \(\{f\le t\}\). It is not unique — \(\operatorname{dist}(x,\{f\le t\})\) works too when the sublevel sets are closed. Prefer a nice, ideally differentiable, \(\varphi_t\).

04 Convex over concave

\(p\) convex with \(p\ge0\), \(q\) concave with \(q>0\) on convex \(C\) \(\Rightarrow\) \(f=p/q\) quasiconvex, with \(\varphi_t=p-tq\) for \(t\ge 0\): convex in \(x\), decreasing in \(t\).

05 Why it is here

The family is the hinge to §4.2.5: with \(\varphi_t\) in hand, "is \(f\) below \(t\) somewhere feasible?" becomes a convex feasibility problem, and bisection on \(t\) solves the quasiconvex problem.

Traps

  • trap 1
    Each \(\varphi_t\) must be convex, not merely quasiconvex. A quasiconvex \(\varphi_t\) would give a convex \(0\)-sublevel set too, but would defeat the purpose — the point is to hand a solver a convex inequality.
  • trap 2
    The direction is \(f(x)\le t\iff\varphi_t(x)\le 0\). Not \(\varphi_t(x)\le t\), not \(f(x)\le 0\); the level is transferred out of the inequality and into the index.
  • trap 3
    Nesting is the requirement; pointwise-nonincreasing-in-\(t\) is one convenient way to secure it. Do not report the sufficient condition as the definition.
  • trap 4
    \(\varphi_t=p-tq\) needs \(t\ge 0\). At negative \(t\) the term \(-tq\) is concave and the family loses convexity — though those sublevel sets are empty anyway.
