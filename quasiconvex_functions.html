Quasiconvex functions: definition and examples

A strict generalization of convexity defined without ever mentioning the epigraph. Everything hangs on one question, asked once for every level \(\alpha\): is the sublevel set \(\{f\le\alpha\}\) a convex set?

Sα = {x ∈ dom f | f(x) ≤ α} convex on R: every sublevel set an interval convex ⟹ quasiconvex, never conversely p. 95–98 · mastery: diagnose
§0where we are

§3.1–§3.3 were about convex functions and the conjugate. §3.4 opens with a strict generalization — quasiconvexity — defined purely through sublevel sets. This subsection is the definition plus a battery of examples, and every one of them drills the same single technique: fix \(\alpha\) and show that \(S_\alpha\) is a convex set.

§1the definition

Convexity of the sets, not of the function

A function \(f:\mathbf{R}^{n}\to\mathbf{R}\) is quasiconvex (or unimodal) if its domain and all its sublevel sets \[ S_\alpha=\{\,x\in\operatorname{dom}f \mid f(x)\le\alpha\,\},\qquad \alpha\in\mathbf{R}, \] are convex. B&V §3.4.1 · L4908–4914

Read the quantifier carefully: all sublevel sets, for every \(\alpha\in\mathbf{R}\), and \(\operatorname{dom}f\) itself. And read the object carefully: what must be convex is the set \(S_\alpha\subseteq\mathbf{R}^{n}\), not the function. Nothing here mentions the epigraph, a chord, or a second derivative.

  • quasiconvex
    \(\operatorname{dom}f\) and every sublevel set \(\{x\mid f(x)\le\alpha\}\) are convex sets.
  • quasiconcave
    \(-f\) is quasiconvex — equivalently every superlevel set \(\{x\mid f(x)\ge\alpha\}\) is convex.
  • quasilinear
    Both quasiconvex and quasiconcave. A consequence is that \(\operatorname{dom}f\) and every level set \(\{x\mid f(x)=\alpha\}\) are convex — but the definition is "both", not "convex level sets".
!

The quasilinear trap. Convex level sets are a consequence of quasilinearity (a level set is the intersection \(\{f\le\alpha\}\cap\{f\ge\alpha\}\) of two convex sets), not the definition. A function can have convex level sets without being quasilinear — define quasilinear as "quasiconvex and quasiconcave" and derive the rest.

§2on R, and the link to convexity

Unimodal, and strictly weaker than convex

On \(\mathbf{R}\), \(f\) is quasiconvex if and only if every sublevel set is an interval (possibly an infinite interval) — hence the synonym unimodal. A convex function has convex sublevel sets, so convex \(\Rightarrow\) quasiconvex; the converse fails, since quasiconvex functions can be concave, or even discontinuous. B&V §3.4.1 · L4937–4941

The convex subsets of \(\mathbf{R}\) are exactly the intervals, so on the line the definition reads: as \(\alpha\) sweeps upward, the set where \(f\) sits below \(\alpha\) must always be one unbroken piece. That is precisely "the function goes down, then goes up" — one mode, no second dip.

The implication convex \(\Rightarrow\) quasiconvex is immediate (§3.1.6: a convex function's sublevel sets are convex). What is worth internalizing is how much information is thrown away going the other direction. Quasiconvexity says nothing about curvature. It constrains only the shape of the sublevel sets — so a quasiconvex function may be concave, may have flat spots, may jump.

§3example 3.29 — functions on R

\(\log x\) and \(\lceil x\rceil\): concave, discontinuous, still quasiconvex

\(\log x\) on \(\mathbf{R}_{++}\) is quasiconvex and quasiconcave, hence quasilinear. So is the ceiling function \(\lceil x\rceil=\inf\{z\in\mathbf{Z}\mid z\ge x\}\), which is not even continuous. B&V §3.4.1 · L4943–4950
Example 3.29a — the logarithmquasilinear on \(\mathbf{R}_{++}\)

\(\log x\) on \(\mathbf{R}_{++}\) is quasiconvex and quasiconcave, i.e. quasilinear. Each sublevel set is \(\{x>0\mid \log x\le\alpha\}=(0,e^{\alpha}]\), an interval; each superlevel set is \([e^{\alpha},\infty)\), also an interval.

And \(\log\) is concave, not convex. So here is a quasiconvex function that is not convex — the converse of "convex \(\Rightarrow\) quasiconvex" is dead on arrival.

Example 3.29b — the ceiling\(\lceil x\rceil=\inf\{z\in\mathbf{Z}\mid z\ge x\}\)

The ceiling function is quasiconvex and quasiconcave as well, despite being discontinuous at every integer. Its sublevel sets are \(\{x\mid\lceil x\rceil\le\alpha\}=(-\infty,\lfloor\alpha\rfloor]\) — intervals — and its superlevel sets are \((\lceil\alpha\rceil-1,\infty)\), also intervals.

The general fact behind both: any monotone function on \(\mathbf{R}\) is quasilinear. If \(f\) is nondecreasing, every sublevel set is a left ray and every superlevel set a right ray, and rays are intervals. Monotonicity is the cheapest possible certificate of quasilinearity.

▲

The moral of Example 3.29. A quasiconvex function can be concave (\(\log x\)) or discontinuous (\(\lceil x\rceil\)). Quasiconvexity constrains only the shape of the sublevel sets; it imposes no curvature, no continuity, no differentiability.

§4example 3.30 — length of a vector

An integer-valued quasiconvex function on \(\mathbf{R}^{n}\)

Define the length of \(x\in\mathbf{R}^{n}\) as the largest index of a nonzero component, \[ f(x)=\max\{\,i\mid x_i\ne 0\,\},\qquad f(0)=0. \] This \(f\) takes values in \(\{0,1,\dots,n\}\) and is quasiconvex on \(\mathbf{R}^{n}\). B&V §3.4.1 · L4953–4958

Fix \(\alpha\) and read off the sublevel set — three cases, and each one is visibly a convex set:

range of α\(S_\alpha=\{x\mid f(x)\le\alpha\}\)convex?
α < 0\(\varnothing\)yes (vacuously)
0 ≤ α < n\(\{x\mid x_i=0 \text{ for } i=\lfloor\alpha\rfloor+1,\dots,n\}\)yes — a coordinate subspace
α ≥ n\(\mathbf{R}^{n}\)yes

The middle row is the substantive one: "length at most \(\lfloor\alpha\rfloor\)" means all components past \(\lfloor\alpha\rfloor\) vanish, which is the linear subspace spanned by the first \(\lfloor\alpha\rfloor\) coordinate vectors. Subspaces are convex, so every sublevel set is convex and \(f\) is quasiconvex — even though \(f\) is integer-valued and wildly discontinuous.

▲

Third witness shape. Across these examples the sublevel set turns out to be one of a small menu of convex objects: an interval (§2–§3), a subspace (here), an intersection of halfspaces (§6, §8), or a ball (§7). Recognizing which one you are looking at is the proof.

§5example 3.31 — the product x₁x₂

Quasiconcave without being concave

\(f(x_1,x_2)=x_1x_2\) on \(\mathbf{R}^{2}_{++}\) is quasiconcave: its superlevel sets \(\{x\in\mathbf{R}^{2}_{++}\mid x_1x_2\ge\alpha\}\) are convex. It is neither convex nor concave, since its Hessian \[ \nabla^{2}f=\begin{bmatrix}0&1\\1&0\end{bmatrix} \] is indefinite (eigenvalues \(\pm 1\)). B&V §3.4.1 · L4962–4976

The Hessian is constant and indefinite, so the second-order conditions of §3.1.4 rule out convexity and concavity outright. Yet the superlevel set \(\{x_1x_2\ge\alpha\}\) inside the positive orthant is the region above a hyperbola — the classic convex "corner" region — for every \(\alpha\). Quasiconcavity survives where concavity dies.

!

The domain is not decoration. \(x_1x_2\) is not quasiconcave on all of \(\mathbf{R}^{2}\). On the full plane, \(\{x_1x_2\ge\alpha\}\) for \(\alpha>0\) is the union of two hyperbola branches — one in the first quadrant, one in the third — and a segment joining them passes through the origin, where the product is \(0<\alpha\). Restricting to the nonnegative orthant is what makes the claim true.

§6example 3.32 — the linear-fractional function

Quasilinear, by clearing one denominator

The linear-fractional function \[ f(x)=\frac{a^{\mathsf T}x+b}{c^{\mathsf T}x+d},\qquad \operatorname{dom}f=\{x\mid c^{\mathsf T}x+d>0\}, \] is quasiconvex and quasiconcave, i.e. quasilinear. B&V §3.4.1 · L4979–4992
Claim — every sublevel set of \(f\) is convexmultiply out, positively
\[ S_\alpha=\Bigl\{\,x \;\Bigm|\; c^{\mathsf T}x+d>0,\ \ \frac{a^{\mathsf T}x+b}{c^{\mathsf T}x+d}\le\alpha \,\Bigr\} \]
why the domain condition travels with the sublevel set — it is part of the definition of \(S_\alpha\), not an afterthought.
\[ =\{\,x\mid c^{\mathsf T}x+d>0,\ \ a^{\mathsf T}x+b\le\alpha\,(c^{\mathsf T}x+d)\,\} \]
why on \(\operatorname{dom}f\) the denominator is strictly positive, so multiplying through preserves the direction of the inequality. This is the whole trick.
\[ =\{\,x\mid c^{\mathsf T}x+d>0\,\}\ \cap\ \{\,x\mid (a-\alpha c)^{\mathsf T}x+(b-\alpha d)\le 0\,\} \]
why both conditions are now affine in \(x\): an open halfspace intersected with a closed halfspace. Convex.
\[ \{x\mid f(x)\ge\alpha\}=\{c^{\mathsf T}x+d>0\}\cap\{(a-\alpha c)^{\mathsf T}x+(b-\alpha d)\ge 0\} \]
why the same multiplication runs with the inequality reversed, so the superlevel sets are convex too — hence quasilinear.

§7example 3.33 — distance ratio

The sublevel set is a Euclidean ball

Let \(a,b\in\mathbf{R}^{n}\) and define \[ f(x)=\frac{\|x-a\|_2}{\|x-b\|_2},\qquad \operatorname{dom}f=\{x\mid \|x-a\|_2\le\|x-b\|_2\}, \] the set of points at least as close to \(a\) as to \(b\). Then \(f\) is quasiconvex there. B&V §3.4.1 · L4995–5012

On that halfspace \(0\le f\le 1\), so only levels \(\alpha\in[0,1]\) matter. The derivation is a squaring followed by a completion of squares:

Claim — \(S_\alpha\) is convex for every \(\alpha\)square, then recognize a ball
\[ \alpha<0:\quad S_\alpha=\varnothing \]
why \(f\ge 0\) everywhere on its domain; the empty set is convex.
\[ \|x-a\|_2\le\alpha\|x-b\|_2 \iff \|x-a\|_2^{2}\le\alpha^{2}\|x-b\|_2^{2} \]
why squaring is an equivalence because both sides are nonnegative — this uses \(\alpha\ge 0\). Cite that hypothesis; it is where the argument would fail otherwise.
\[ (1-\alpha^{2})\,x^{\mathsf T}x-2(a-\alpha^{2}b)^{\mathsf T}x+a^{\mathsf T}a-\alpha^{2}b^{\mathsf T}b\ \le\ 0 \]
why expand both norms and collect. For \(0\le\alpha<1\) the coefficient \(1-\alpha^{2}>0\), so this is a convex quadratic inequality — a Euclidean ball.
\[ \alpha=1:\quad -2(a-b)^{\mathsf T}x+a^{\mathsf T}a-b^{\mathsf T}b\le 0 \]
why the \(x^{\mathsf T}x\) term vanishes when \(1-\alpha^{2}=0\), leaving an affine inequality — a halfspace, which is the domain itself.

Explicitly, for \(0\le\alpha<1\) the ball has center and radius

\[ x_c=\frac{a-\alpha^{2}b}{1-\alpha^{2}},\qquad r^{2}=\|x_c\|_2^{2}-\frac{a^{\mathsf T}a-\alpha^{2}b^{\mathsf T}b}{1-\alpha^{2}}, \]

the classical circle of Apollonius. Every sublevel set is empty, a ball, or a halfspace — all convex — so \(f\) is quasiconvex on \(\{\|x-a\|_2\le\|x-b\|_2\}\).

§8example 3.34 — internal rate of return

A quasiconcave function of a cash flow

Let \(x=(x_0,\dots,x_n)\in\mathbf{R}^{n+1}\) be a cash flow over \(n\) periods, \(x_i\) the payment in period \(i\). The present value at interest rate \(r\ge 0\) is

\[ \mathrm{PV}(x,r)=\sum_{i=0}^{n}(1+r)^{-i}x_i , \]

which is a linear function of \(x\) for each fixed \(r\) — that is the hinge of the whole example.

Assume \(x_0<0\) (an initial investment) and \(x_0+x_1+\cdots+x_n>0\) (the total return exceeds the investment). The internal rate of return is \[ \mathrm{IRR}(x)=\inf\{\,r\ge 0\mid \mathrm{PV}(x,r)=0\,\}, \] and \(\mathrm{IRR}\) is quasiconcave. B&V §3.4.1 · L5015–5047
Claim — every superlevel set of IRR is convexturn a level into an intersection
\[ \mathrm{IRR}(x)\ge R \iff \mathrm{PV}(x,r)>0\ \ \text{for all } 0\le r<R \]
why the IRR is the first rate at which the present value hits zero; it is at least \(R\) exactly when the present value has not yet vanished anywhere below \(R\).
\[ \{x\mid \mathrm{IRR}(x)\ge R\}=\bigcap_{0\le r<R}\{\,x\mid \mathrm{PV}(x,r)>0\,\} \]
why "for all \(r\)" is an intersection. Each member is an open halfspace, because \(\mathrm{PV}(\cdot,r)\) is linear in \(x\).
\[ \text{an intersection of convex sets is convex}\ \Rightarrow\ \mathrm{IRR}\ \text{quasiconcave} \]
why §2.3.1 — arbitrary, even infinite, intersections preserve convexity. Note the intersection is over a continuum of \(r\).
▲

The design move. IRR is defined by an infimum and is nothing like linear in \(x\). The trick is not to analyze IRR at all, but to rewrite the level condition \(\mathrm{IRR}(x)\ge R\) as a family of conditions that are each linear in \(x\). Whenever a level condition can be restated as "for all \(t\), something affine holds", you get convexity of the level set for free.

§9expert lens · mastery: diagnose

What to have loaded when you meet a new function

01The definition, stated correctly

\(f\) is quasiconvex \(\iff\) \(\operatorname{dom}f\) and all sublevel sets \(\{f\le\alpha\}\) are convex sets. Not about curvature, not about the epigraph.

02The variants

Quasiconcave \(\iff\) convex superlevel sets. Quasilinear \(\iff\) both, which forces convex level sets \(\{f=\alpha\}\).

03The link to convexity

Convex \(\Rightarrow\) quasiconvex, never conversely. Quasiconvex functions can be concave (\(\log x\)) or discontinuous (\(\lceil x\rceil\)); any monotone function on \(\mathbf{R}\) is quasilinear.

04The one technique

Fix \(\alpha\), write down \(S_\alpha\), and recognize it: intersection of halfspaces (linear-fractional, IRR), a ball (distance ratio), a subspace (vector length), an interval (functions on \(\mathbf{R}\)). Quasiconcavity: same move on superlevel sets.

05The traps

"Quasiconvex" is not "convex sublevel function" — it is convex sublevel sets. Quasiconcave uses superlevel sets. \(x_1x_2\) is quasiconcave on \(\mathbf{R}^{2}_{+}\), not on \(\mathbf{R}^{2}\). The distance ratio is shown quasiconvex on the halfspace where \(f\le 1\).

Summary · 2026-08-04 · bv.3.4.1 · Quasiconvex functions: definition & examples (B&V §3.4.1)

Main points for quick review

Definition

\(f\) quasiconvex \(\iff\) \(\operatorname{dom}f\) and all sublevel sets \(S_\alpha=\{x\in\operatorname{dom}f\mid f(x)\le\alpha\}\) are convex SETS. On \(\mathbf{R}\): intervals — unimodal.

Variants

Quasiconcave \(\iff\) convex superlevel sets; quasilinear \(\iff\) both \(\Rightarrow\) convex level sets.

Convexity

Convex \(\Rightarrow\) quasiconvex, NOT conversely; quasiconvex functions can be concave (\(\log x\)) or discontinuous (\(\lceil x\rceil\)).

Technique

Prove quasiconvexity by showing each \(S_\alpha\) is convex — halfspace intersection (linear-fractional), ball (distance ratio), or subspace (vector length).

Quasiconcave examples

\(x_1x_2\) on \(\mathbf{R}^{2}_{+}\) (indefinite Hessian); IRR (superlevel set = intersection of open halfspaces).
