§0where we are

§4.1.1 fixed the vocabulary of the standard-form problem (4.1). This subsection is the mechanics of getting a problem into that form: how to zero out the right-hand sides, the canonical box-constraint example, and how a maximization is handled. Still the general problem — no convexity assumed (that's §4.2), and the deeper equivalence transformations are §4.1.3.

§1the standard-form convention

We call (4.1) the standard form. The convention is that the right-hand sides of the inequality and equality constraints are zero. Any nonzero RHS is subtracted off:

an equality \(g_i(x)=\tilde g_i(x)\) is represented as \(h_i(x)=0\) with \(h_i(x)=g_i(x)-\tilde g_i(x)\);
an inequality \(f_i(x)\ge 0\) is represented as \(-f_i(x)\le 0\). B&V L6613–6618

Two moves: move everything to one side (RHS becomes 0), and for a ≥ constraint, negate so it reads ≤ 0. So a(x) ≤ b(x) becomes a(x) − b(x) ≤ 0; a(x) ≥ b(x) becomes b(x) − a(x) ≤ 0.

§2example 4.2 — box constraints
minimize \(f_0(x)\)
subject to \(l_i\le x_i\le u_i,\quad i=1,\dots,n\) B&V L6620–6641

with x ∈ Rⁿ. These are variable bounds (each xᵢ gets a lower and upper bound) or box constraints (the feasible set is a box). Each two-sided bound lᵢ ≤ xᵢ ≤ uᵢ splits into two one-sided constraints:

minimize \(f_0(x)\)
subject to \(l_i-x_i\le 0,\quad i=1,\dots,n\)
        \(x_i-u_i\le 0,\quad i=1,\dots,n\) B&V L6620–6641

There are 2n inequality constraint functions: fᵢ(x) = lᵢ − xᵢ (i = 1..n) and fᵢ(x) = x_{i−n} − u_{i−n} (i = n+1..2n).

!

The key point: n two-sided bounds become 2n one-sided ≤ 0 constraints.

§3maximization problems

By convention we work with minimization. A maximization problem (4.2)

maximize \(f_0(x)\) subject to \(f_i(x)\le 0,\ h_i(x)=0\)B&V L6643–6659

is solved by minimizing −f₀ over the same constraints. The feasible set is unchanged, and the §4.1.1 terms carry over with the natural sign flips:

  • optimal value
    \(p^\star=\sup\{\,f_0(x)\mid f_i(x)\le0,\ h_i(x)=0\,\}\) (note sup, not inf), and it equals −inf{−f₀(x) | x feasible} — the negative of the optimal value of minimize −f₀ (an infimum, which need not be attained).
  • ε-suboptimal
    A feasible x is ε-suboptimal if f₀(x) ≥ p⋆ − ε (the inequality flips relative to the minimization case f₀(x) ≤ p⋆ + ε).
  • utility
    For a maximization the objective is sometimes called the utility or satisfaction level rather than the cost.

A point x is optimal for maximize f₀ iff it is optimal for minimize −f₀; the two are equivalent, with optimal values related by p⋆_max = −p⋆_min.

!

Using the minimization ε-sign (f₀(x) ≤ p⋆ + ε) for a maximization problem is the recurring slip — check which direction "sub-optimal" points.

§4expert lens — what to keep straight (diagnose)

E1Zero-RHS convention

Move everything to one side. a ≤ b → a − b ≤ 0; a ≥ b → b − a ≤ 0; gᵢ = g̃ᵢ → gᵢ − g̃ᵢ = 0.

E2≥ needs a negation

fᵢ ≥ 0 → −fᵢ ≤ 0. Forgetting the sign flip is the classic error.

E3Box constraints

n two-sided bounds → 2n one-sided functions; feasible set is a box.

E4Maximization

max f₀ ≡ min −f₀ over the same feasible set; p⋆ = sup f₀ = −p⋆_min; ε-suboptimal f₀(x) ≥ p⋆ − ε (flipped); objective is a "utility."

E5Traps

Leaving a nonzero RHS; writing a ≥ 0 (not ≤ 0) inequality in standard form; using the minimization ε-sign (≤ p⋆ + ε) for a maximization; counting n instead of 2n box constraints.

E6Scope

Mechanics only — equivalence transformations (change of variables, slack variables, epigraph form) are §4.1.3; convexity is §4.2.

Summary · 2026-09-01 · bv.4.1.2 · Expressing problems in standard form (B&V §4.1.2)

Main points for quick review

Zero-RHS convention

Subtract off nonzero right-hand sides. Equality \(g_i=\tilde g_i\) → \(g_i-\tilde g_i=0\); inequality \(f_i\ge0\) → \(-f_i\le0\) (\(a\ge b\) → \(b-a\le0\)).

Box constraints (Ex 4.2)

\(l_i\le x_i\le u_i\) (\(i{=}1..n\)) → 2n one-sided constraints \(l_i-x_i\le0\) and \(x_i-u_i\le0\); feasible set is a box.

Maximization

\(\text{maximize } f_0\) is solved by \(\text{minimize } -f_0\) over the same feasible set; \(p^\star=\sup f_0=-p^\star_{\min}\); ε-suboptimal \(f_0(x)\ge p^\star-\varepsilon\); objective = utility/satisfaction.

Scope

Conventions only; equivalence transformations are §4.1.3, convexity is §4.2.
