§0where we are

§4.1 defined the general optimization problem, no convexity assumed. §4.2 specializes to convex problems. Everything good about convex optimization — local optima are global (§4.2.2), tractable algorithms exist — flows from getting this definition exactly right, including a subtlety about how the feasible set is described, not just what it looks like. That subtlety is the whole job of this section.

§1definition — B&V Eq. (4.15)
minimize \(f_0(x)\)
subject to \(f_i(x)\le0,\ i=1,\dots,m\)
        \(a_i^{\mathsf T}x=b_i,\ i=1,\dots,p\)
with \(f_0,\dots,f_m\) convex. B&V Eq. (4.15) · L6998–7011

Three additional requirements over the general standard form (4.1):

  • objective
    \(f_0\) must be convex.
  • inequalities
    each \(f_i\) must be convex.
  • equalities
    each \(h_i(x)=a_i^{\mathsf T}x-b_i\) must be affine — a linear equality, not merely convex.
!

The third catches people: a convex equality function is not enough — it must be affine. Convexity of \(h\) doesn't qualify it.

a nonaffine h may or may not have a convex zero set
\((x_1+x_2)^2=0\)
cuts out the line \(x_1+x_2=0\) — convex, and reformulable as an affine equality (§5).
\(x_1^2+x_2^2=1\)
cuts out the unit circle — not convex.
→

Either way — convex zero set or not — a description with a nonaffine \(h\) fails the standard-form definition. §5 works through exactly this case.

§2the feasible set is convex

It is the intersection of three convex pieces:

  • domain
    \(\mathcal D=\bigcap_{i=0}^m \operatorname{dom} f_i\) — convex.
  • sublevel sets
    the \(m\) convex sublevel sets \(\{x\mid f_i(x)\le0\}\) (§3.1.3).
  • hyperplanes
    the \(p\) hyperplanes \(\{x\mid a_i^{\mathsf T}x=b_i\}\) — affine.
∩

An intersection of convex sets is convex (§2.3.1), so the feasible set is convex. A convex problem minimizes a convex objective over a convex set.

!

WLOG \(a_i\ne0\): \(a_i=b_i=0\) means the constraint is vacuous — delete it. \(a_i=0,\ b_i\ne0\) means it's inconsistent — the problem is infeasible.

§3quasiconvex variant and optimal-set facts
If \(f_0\) is quasiconvex — still convex \(f_i\), still affine equalities — the problem is a (standard-form) quasiconvex problem. B&V L7025–7030

Since sublevel sets of convex and quasiconvex functions are convex, three facts follow:

  • ε-suboptimal
    the \(\epsilon\)-suboptimal sets are convex.
  • optimal set
    in particular, the optimal set is convex.
  • uniqueness
    if \(f_0\) is strictly convex, the optimal set has at most one point.
!

"At most one point" is uniqueness, not existence — strict convexity rules out a second minimizer, but a minimizer may not exist at all.

§4concave maximization problems
maximize \(f_0(x)\) subject to \(f_i(x)\le0,\ a_i^{\mathsf T}x=b_i\) is also called a convex optimization problem when \(f_0\) is concave and the \(f_i\) are convex. B&V L7032–7044

Solved by minimizing the convex \(-f_0\) — every result about convex minimization transposes directly. (Quasiconvex when \(f_0\) is quasiconcave.)

§5the subtlety — standard form vs "convex over convex"

Consider (4.17), \(x\in\mathbf R^2\):

minimize \(x_1^2+x_2^2\)
subject to \(f_1(x)=\dfrac{x_1}{1+x_2^2}\le0\)
        \(h_1(x)=(x_1+x_2)^2=0\) B&V (4.17) · L7046–7083

This is in the general standard form (4.1), but not a convex optimization problem in standard form: \(h_1\) is not affine and \(f_1\) is not convex. Yet its feasible set is convex — since \(1+x_2^2>0\) always, \(f_1(x)\le0\iff x_1\le0\); and \((x_1+x_2)^2=0\iff x_1+x_2=0\). So the feasible set is \(\{x\mid x_1\le0,\ x_1+x_2=0\}\) — convex.

!

We are minimizing a convex function over a convex set here — but by B&V's definition this is still not a convex problem, because of how it's described.

Reformulated as (4.18):

minimize \(x_1^2+x_2^2\)
subject to \(\tilde f_1(x)=x_1\le0\)
        \(\tilde h_1(x)=x_1+x_2=0\) B&V (4.18) · L7046–7083

Now \(f_0,\tilde f_1\) are convex and \(\tilde h_1\) is affine — (4.18) is a convex problem in standard form. (4.17) and (4.18) are equivalent, but only (4.18) qualifies.

!

B&V's stricter definition: a convex problem is not merely "minimize a convex function over a convex set" — some authors call that an abstract convex problem (a term B&V does not use). It also requires the feasible set be described specifically by convex inequalities and affine equalities. Rarely bites in practice: finding such a description is usually straightforward.

§6expert lens — what to keep straight (diagnose)

E1Definition (4.15)

\(f_0,f_i\) convex, equalities \(a_i^{\mathsf T}x=b_i\) affine — the affine-equality condition is the load-bearing extra requirement.

E2Feasible set convex

Intersection of \(\mathcal D\), convex sublevel sets, hyperplanes. Minimize convex over convex. WLOG \(a_i\ne0\).

E3Optimal-set facts

\(\epsilon\)-suboptimal & optimal sets convex (also for quasiconvex \(f_0\)); strictly convex \(f_0\) ⟹ at most one optimizer.

E4Concave maximization

Concave \(f_0\), convex \(f_i\) = convex problem, solved via \(\min -f_0\).

E5The subtlety

"Convex over convex" is not sufficient — the description must use convex inequalities + affine equalities. (4.17) is not convex-in-standard-form; (4.18) is.

E6Traps

Equalities must be affine (not convex); a convex feasible set alone doesn't make a convex problem; strict-convex uniqueness is "at most one" (a minimizer may not exist).

E7Scope

Definition only. Local ⟹ global is §4.2.2, optimality criterion §4.2.3, problem classes (LP/QP/…) §4.3+.

Main points for quick review

Definition (4.15)

min \(f_0\) s.t. \(f_i\le0\), \(a_i^{\mathsf T}x=b_i\), with \(f_0,\dots,f_m\) convex and equalities affine. Three requirements: objective convex, inequality functions convex, equality functions affine.

Feasible set convex

Intersection of \(\mathcal D\), convex sublevel sets \(\{f_i\le0\}\), hyperplanes \(\{a_i^{\mathsf T}x=b_i\}\) — minimize convex over convex (WLOG \(a_i\ne0\)).

Optimal set

\(\epsilon\)-suboptimal & optimal sets convex (also quasiconvex \(f_0\)); strictly convex ⟹ at most one optimizer. Concave max (concave \(f_0\), convex \(f_i\)) is a convex problem via \(\min -f_0\).

The subtlety

Convex-over-convex is not sufficient — needs the convex-inequality + affine-equality description. (4.17) not convex-in-standard-form (nonaffine \(h_1\), nonconvex \(f_1\)); equivalent (4.18) is. B&V rejects the "abstract" definition.
