The conjugate function

Fix a slope y, tilt f by yᵀx, and record the largest gap. The result is convex whether or not f is — and it turns quadratics into inverse quadratics, log-sum-exp into entropy, and norms into indicator functions of dual balls.

f*(y) = sup (yᵀx − f(x)) always convex a domain AND a formula p. 91–94 · mastery: diagnose
§0where we are

§3.2 gave a list of operations that preserve convexity. §3.3 introduces something different: a transform. The conjugate \(f^{*}\) maps a function \(f\) to a new function that will turn out to be central to duality. This subsection gives the definition, the one structural fact about it, and a battery of worked conjugates — the pairs worth memorizing.

§1definition (3.18)
Let \(f:\mathbf R^{n}\to\mathbf R\). The function \(f^{*}:\mathbf R^{n}\to\mathbf R\), defined as \[ f^{*}(y)=\sup_{x\in\operatorname{dom}f}\big(y^{\mathsf T}x-f(x)\big), \tag{3.18}\] is called the conjugate of the function \(f\). The domain of the conjugate function consists of \(y\in\mathbf R^{n}\) for which the supremum is finite, i.e. for which the difference \(y^{\mathsf T}x-f(x)\) is bounded above on \(\operatorname{dom}f\). B&V §3.3.1 · L4665–4672

Read the formula as a procedure. Fix a slope vector \(y\). Tilt \(f\) by subtracting it from the linear function \(y^{\mathsf T}x\). Record the largest gap \(y^{\mathsf T}x-f(x)\) over the domain of \(f\). That number, as a function of the slope, is \(f^{*}\).

!

A conjugate is a domain and a formula. Half the work of any conjugate calculation is deciding for which \(y\) the supremum is finite at all — the answer \(\operatorname{dom}f^{*}\) is as much part of the result as the closed-form expression.

§2f* is always convex
The conjugate function \(f^{*}\) is a convex function, whether or not \(f\) is convex.B&V §3.3.1 · L4674–4677
Claim: f* is convex for any fpointwise supremum of affine functions
\[ \ell_{x}(y)=y^{\mathsf T}x-f(x) \]
fix \(x\). holding \(x\) fixed, \(f(x)\) is just a constant; the expression is a linear function of \(y\) minus a constant.
\[ \ell_{x}\ \text{is affine in } y \quad\text{for each } x\in\operatorname{dom}f \]
the crux. the variable of \(f^{*}\) is \(y\), not \(x\). in \(y\), each member of the family is affine — and affine functions are convex.
\[ f^{*}=\sup_{x\in\operatorname{dom}f}\ \ell_{x} \]
conclude. \(f^{*}\) is the pointwise supremum of a family of affine functions of \(y\), hence convex by §3.2.3 — no assumption on \(f\) anywhere. ∎
+

Convention. When \(f\) is convex we may drop the subscript \(x\in\operatorname{dom}f\) and write \(f^{*}(y)=\sup_{x}(y^{\mathsf T}x-f(x))\), using the extended-value convention (§3.1.2) that \(y^{\mathsf T}x-f(x)=-\infty\) for \(x\notin\operatorname{dom}f\) — those points simply never win the supremum.

§3geometric reading — figure 3.8

For \(n=1\) the definition has a picture attached, and the picture is the thing to remember.

  • the gap
    \(f^{*}(y)\) is the maximum gap between the line \(x\mapsto yx\) and the graph of \(f\), measured vertically.
  • below f
    Since \(yx-f^{*}(y)\le f(x)\) for every \(x\) — that inequality is the definition of the supremum, rearranged — the line \(x\mapsto yx-f^{*}(y)\) lies below the graph of \(f\).
  • intercept
    That line has slope \(y\) and crosses the vertical axis at height \(-f^{*}(y)\): the intercept point is \(\big(0,\,-f^{*}(y)\big)\). Note the minus sign.
  • touching
    If the supremum is attained — for differentiable \(f\), at the \(x\) with \(f'(x)=y\) — the line touches the graph there and supports it. Attainment is not automatic: for \(f(x)=e^{x}\) at \(y=0\) the supremum is the finite value \(0\), approached only as \(x\to-\infty\), so no point of contact exists.
!

Finite and attained are different conditions. \(y\in\operatorname{dom}f^{*}\) requires only that the supremum be finite; the supporting-line picture requires that it be achieved at some \(x\).

§4the solving recipe

Every conjugate in this section is computed the same way, in two movements.

  • 1 · domain
    Boundedness. For which \(y\) is \(y^{\mathsf T}x-f(x)\) bounded above on \(\operatorname{dom}f\)? The standard tool is a direction argument: push \(x\) along a ray, \(t\to\infty\), and watch the expression. If it grows without bound for some ray, that \(y\notin\operatorname{dom}f^{*}\).
  • 2 · value
    Stationarity. When \(f\) is differentiable and the maximum is attained in the interior, set the gradient of \(y^{\mathsf T}x-f(x)\) to zero: \(y-\nabla f(x)=0\), i.e. \(y=\nabla f(x)\). Solve for \(x\), back-substitute into \(y^{\mathsf T}x-f(x)\).
!

Stationarity is not universal. Norms and indicator functions are not differentiable, and their conjugates come out of an inequality — \(y^{\mathsf T}x\le\|y\|_{*}\|x\|\) — or straight from the support-function definition. Boundary and non-attained cases are settled by limits. Reach for \(y=\nabla f(x)\) only when smoothness and interior attainment are both in hand.

§5example 3.21 — five scalar conjugates
We first consider some convex functions on \(\mathbf R\).B&V §3.3.1 · Example 3.21 · L4682–4703

affine function \(f(x)=ax+b\)dom f* = {a}

By definition, \(yx-ax-b\) is bounded above if and only if \(y-a=0\) — otherwise send \(x\to\pm\infty\) in the direction that makes it grow. So \(\operatorname{dom}f^{*}=\{a\}\), and there \(f^{*}(a)=-b\). A degenerate but instructive case: the domain is a single point, and the formula is a single number.

negative logarithm \(f(x)=-\log x\), \(\operatorname{dom}f=\mathbf R_{++}\)dom f* = −R₊₊

The function \(yx+\log x\) is unbounded above for \(y\ge 0\) (take \(x\to\infty\)), and reaches its maximum at \(x=-1/y\) when \(y<0\). Substituting: \(f^{*}(y)=-\log(-y)-1\) for \(y<0\).

exponential \(f(x)=e^{x}\)dom f* = R₊, with 0 log 0 = 0

Three cases, and the third is the interesting one. \(yx-e^{x}\) is unbounded above if \(y<0\) (take \(x\to-\infty\)). For \(y>0\), the maximum sits at \(x=\log y\), giving \(f^{*}(y)=y\log y-y\). For \(y=0\) the expression is \(-e^{x}\), whose supremum is \(0\) — finite but never attained. So \(f^{*}(0)=0\), and with the convention \(0\log 0=0\) the single formula \(f^{*}(y)=y\log y-y\) covers the whole domain \(\mathbf R_{+}\).

negative entropy \(f(x)=x\log x\), \(\operatorname{dom}f=\mathbf R_{+}\) (with \(0\log 0=0\))dom f* = R

Here \(yx-x\log x\) is bounded above on \(\mathbf R_{+}\) for every \(y\) — the \(-x\log x\) term eventually dominates any linear term. The maximum is at \(x=e^{\,y-1}\), so \(f^{*}(y)=e^{\,y-1}\), with \(\operatorname{dom}f^{*}=\mathbf R\).

inverse \(f(x)=1/x\), \(\operatorname{dom}f=\mathbf R_{++}\)dom f* = −R₊

\(yx-1/x\) is unbounded above for \(y>0\). For \(y=0\) the supremum is \(0\) (as \(x\to\infty\)), and for \(y<0\) it is attained at \(x=(-y)^{-1/2}\). Both cases are captured by \(f^{*}(y)=-2(-y)^{1/2}\) on \(\operatorname{dom}f^{*}=-\mathbf R_{+}\).

!

Notice the pattern in the domains: the shape of \(\operatorname{dom}f^{*}\) is dictated entirely by which slopes \(f\) eventually outruns. A function that grows slowly (like \(-\log x\) or \(1/x\)) admits only a thin set of slopes; one that grows fast (like \(x\log x\)) admits them all.

§6example 3.22 — strictly convex quadratic
Consider \(f(x)=\tfrac12 x^{\mathsf T}Qx\), with \(Q\in\mathbf S^{n}_{++}\). The function \(y^{\mathsf T}x-\tfrac12 x^{\mathsf T}Qx\) is bounded above as a function of \(x\) for all \(y\); it attains its maximum at \(x=Q^{-1}y\), so \[ f^{*}(y)=\tfrac12\,y^{\mathsf T}Q^{-1}y,\qquad \operatorname{dom}f^{*}=\mathbf R^{n}. \] B&V §3.3.1 · Example 3.22 · L4706–4714

Positive definiteness is doing two jobs at once: it makes the quadratic term dominate every linear term (so the supremum is finite for all \(y\), and \(\operatorname{dom}f^{*}\) is everything), and it makes \(Q\) invertible so the stationarity equation \(y=Qx\) has the unique solution \(x=Q^{-1}y\).

!

The shape is preserved and the matrix is inverted: \(\tfrac12 x^{\mathsf T}Qx \ \leftrightarrow\ \tfrac12 y^{\mathsf T}Q^{-1}y\). Taking \(Q=I\) gives \(\tfrac12\|x\|_{2}^{2}\), which is its own conjugate — the one genuinely self-conjugate function to keep in mind.

§7example 3.23 — log-determinant
Let \(f(X)=\log\det X^{-1}\) on \(\mathbf S^{n}_{++}\). Its conjugate is \[ f^{*}(Y)=\sup_{X\succ 0}\ \big(\operatorname{tr}(YX)+\log\det X\big), \] which is unbounded above unless \(Y\prec 0\). For \(Y\prec 0\) the supremum is attained at \(X=-Y^{-1}\), giving \[ f^{*}(Y)=\log\det(-Y)^{-1}-n,\qquad \operatorname{dom}f^{*}=-\mathbf S^{n}_{++}. \] B&V §3.3.1 · Example 3.23 · L4718–4742
the matrix version of the recipeinner product is tr(YX)
\[ f^{*}(Y)=\sup_{X\succ0}\big(\operatorname{tr}(YX)-\log\det X^{-1}\big)=\sup_{X\succ0}\big(\operatorname{tr}(YX)+\log\det X\big) \]
set up. on \(\mathbf S^{n}\) the standard inner product \(y^{\mathsf T}x\) becomes \(\operatorname{tr}(YX)\); and \(\log\det X^{-1}=-\log\det X\).
\[ \text{unbounded unless } Y\prec 0 \]
domain first. the direction argument: if \(Y\not\prec0\) there is a ray along which \(\operatorname{tr}(YX)\) grows at least as fast as \(\log\det X\) decays, and the expression blows up.
\[ \nabla_X\big(\operatorname{tr}(YX)+\log\det X\big)=Y+X^{-1}=0 \;\Longrightarrow\; X=-Y^{-1} \]
stationarity. uses \(\nabla\log\det X=X^{-1}\) (§A.4.1). the solution is positive definite exactly because \(Y\prec0\) — the domain condition and the maximizer are the same fact.
\[ f^{*}(Y)=\operatorname{tr}\!\big(Y(-Y^{-1})\big)+\log\det(-Y^{-1})=\log\det(-Y)^{-1}-n \]
back-substitute. \(\operatorname{tr}(-I)=-n\) supplies the constant. ∎
+

Structurally identical to the scalar \(-\log x\): the domain is the negative of the original cone, and the answer is the same log-determinant shape with a constant subtracted. Compare \(-\log(-y)-1\) at \(n=1\).

§8example 3.24 — indicator gives the support function
Let \(I_{S}\) be the indicator function of a set \(S\subseteq\mathbf R^{n}\): \(I_{S}(x)=0\) on \(S\) (and \(+\infty\) otherwise), a set-membership penalty with \(\operatorname{dom}I_{S}=S\). Its conjugate is \[ I_{S}^{*}(y)=\sup_{x\in S} y^{\mathsf T}x, \] the support function of the set \(S\).B&V §3.3.1 · Example 3.24 · L4747–4754

No calculus at all: with \(f\equiv 0\) on \(S\), the objective \(y^{\mathsf T}x-f(x)\) collapses to \(y^{\mathsf T}x\) and the supremum runs over \(S\) alone. Note that \(S\) need not be convex — \(I_{S}^{*}\) is convex regardless, exactly as §2 promised.

+

This is the bridge between the function world and the set world: sets enter the conjugate calculus as indicator functions, and come out as support functions. The construction reappears immediately in §10, where the conjugate of a norm turns out to be the indicator of a ball.

§9example 3.25 — log-sum-exp ↔ negative entropy
The conjugate of the log-sum-exp function \(f(x)=\log\sum_{i=1}^{n}e^{x_i}\) is \[ f^{*}(y)=\begin{cases}\sum_{i=1}^{n} y_i\log y_i & \text{if } y\succeq 0 \text{ and } \mathbf 1^{\mathsf T}y=1,\\[4pt] \infty & \text{otherwise,}\end{cases} \] the negative entropy, restricted to the probability simplex.B&V §3.3.1 · Example 3.25 · L4759–4792
solving y = ∇f(x)the domain falls out of the equation
\[ y_i=\frac{\partial f}{\partial x_i}=\frac{e^{x_i}}{\sum_{j=1}^{n}e^{x_j}} \]
stationarity. the gradient of log-sum-exp is the softmax. this is where the domain is decided, before any value is computed.
\[ \text{solvable for } x \iff y\succ 0 \ \text{and}\ \mathbf 1^{\mathsf T}y=1 \]
read the constraint off. the softmax outputs are strictly positive and sum to one — no other \(y\) can be the gradient at any \(x\).
\[ f^{*}(y)=\sum_{i=1}^{n} y_i\log y_i \]
back-substitute. with \(x_i=\log y_i+c\) any constant \(c\) works, since the objective is invariant under \(x\mapsto x+c\mathbf 1\) when \(\mathbf 1^{\mathsf T}y=1\).
\[ y\succeq 0,\ \mathbf 1^{\mathsf T}y=1 \ \text{ with some } y_i=0:\quad f^{*}(y)=\textstyle\sum_i y_i\log y_i \]
boundary by limits. the supremum is finite but not attained; the value extends continuously using \(0\log0=0\). off the simplex — \(y\not\succeq0\) or \(\mathbf 1^{\mathsf T}y\ne1\) — a direction argument sends the objective to \(+\infty\).
!

Two traps live here. First, the sign: it is \(+\sum_i y_i\log y_i\) — the negative entropy, a convex function, not the entropy itself. Second, never drop the simplex: the constraint set \(\{y\succeq0,\ \mathbf 1^{\mathsf T}y=1\}\) is \(\operatorname{dom}f^{*}\), and stating the formula without it is stating a different function.

§10examples 3.26–3.27 — norm and norm squared

Both results are stated in terms of the dual norm \(\|y\|_{*}=\sup\{y^{\mathsf T}x\mid \|x\|\le 1\}\), and both come from the inequality \(y^{\mathsf T}x\le\|y\|_{*}\|x\|\) rather than from stationarity.

Let \(\|\cdot\|\) be a norm on \(\mathbf R^{n}\), with dual norm \(\|\cdot\|_{*}\). The conjugate of \(f(x)=\|x\|\) is \[ f^{*}(y)=\begin{cases}0 & \|y\|_{*}\le 1,\\ \infty & \text{otherwise,}\end{cases} \] i.e. the indicator function of the dual norm's unit ball.B&V §3.3.1 · Example 3.26 · L4795–4812

If \(\|y\|_{*}\le 1\) then \(y^{\mathsf T}x\le\|x\|\) for all \(x\), so \(y^{\mathsf T}x-\|x\|\) is never positive — and equals \(0\) at \(x=0\); the supremum is \(0\). If \(\|y\|_{*}>1\) there is an \(x\) with \(\|x\|\le1\) and \(y^{\mathsf T}x>1\); scaling \(x\to tx\) with \(t\to\infty\) sends \(y^{\mathsf T}(tx)-\|tx\|=t(y^{\mathsf T}x-\|x\|)\) to \(\infty\). The direction argument, in one line.

The conjugate of \(f(x)=\tfrac12\|x\|^{2}\) is \[ f^{*}(y)=\tfrac12\|y\|_{*}^{2}. \] B&V §3.3.1 · Example 3.27 · L4815–4828

From \(y^{\mathsf T}x\le\|y\|_{*}\|x\|\) we get \(y^{\mathsf T}x-\tfrac12\|x\|^{2}\le\|y\|_{*}\|x\|-\tfrac12\|x\|^{2}\); the right side is a quadratic in the scalar \(\|x\|\), maximized at \(\|x\|=\|y\|_{*}\) with value \(\tfrac12\|y\|_{*}^{2}\), and that bound is achieved. Primal norm in, dual norm out — and the domain is all of \(\mathbf R^{n}\), unlike the plain norm.

!

The single most common error in this section is writing \(\|y\|\) where the answer calls for \(\|y\|_{*}\). The conjugate always speaks in the dual norm. (Only for \(\|\cdot\|_2\), which is self-dual, do the two coincide — which is precisely why it is a bad case to memorize from.)

§11example 3.28 — revenue and profit
Suppose a company produces \(n\) products in quantities \(r\), and \(S(r)\) is the gross sales revenue. With unit production costs \(p\), the maximum profit is \[ M(p)=\sup_{r}\big(S(r)-p^{\mathsf T}r\big)=(-S)^{*}(-p). \] B&V §3.3.1 · Example 3.28 · L4831–4846

Match the pieces against (3.18): the conjugate of \(-S\) evaluated at \(-p\) reads \(\sup_{r}\big((-p)^{\mathsf T}r-(-S(r))\big)=\sup_{r}\big(S(r)-p^{\mathsf T}r\big)\), which is exactly \(M(p)\). Two sign flips — one on the function, one on the argument — because the natural economic statement is a maximization of revenue minus cost rather than the conjugate's linear minus function.

!

The payoff: because \(f^{*}\) is convex for any \(f\) (§2), the maximum profit \(M\) is a convex function of the prices \(p\) — with no assumption whatsoever about the shape of the revenue function \(S\).

§12expert lens — what to keep straight (diagnose)

D1Definition = domain and formula

\(f^{*}(y)=\sup_{x\in\operatorname{dom}f}(y^{\mathsf T}x-f(x))\), with \(\operatorname{dom}f^{*}=\{y\mid \text{the sup is finite}\}\). A conjugate quoted without its domain is incomplete.

D2Always convex

Pointwise supremum of functions affine in \(y\) ⇒ convex, regardless of \(f\). The one structural fact of the subsection.

D3The recipe

Boundedness / direction argument ⇒ \(\operatorname{dom}f^{*}\). Value via \(y=\nabla f(x)\) only for smooth maxima attained in the interior; otherwise inequalities (\(y^{\mathsf T}x\le\|y\|_{*}\|x\|\)), support-function definitions, or limits.

D4Geometry

\(f^{*}(y)\) = max gap between \(yx\) and \(f\); the line \(yx-f^{*}(y)\) lies below \(f\) with intercept \(\big(0,-f^{*}(y)\big)\); it supports the graph only where the sup is attained.

D5Marquee pairs

\(\tfrac12x^{\mathsf T}Qx\leftrightarrow\tfrac12y^{\mathsf T}Q^{-1}y\) (and \(\tfrac12\|x\|_2^2\) self-conjugate); log-sum-exp \(\leftrightarrow\) negative entropy on \(\{y\succeq0,\ \mathbf 1^{\mathsf T}y=1\}\); norm \(\leftrightarrow\) dual-ball indicator; \(\tfrac12\|x\|^{2}\leftrightarrow\tfrac12\|y\|_{*}^{2}\); indicator \(\leftrightarrow\) support function; \(\log\det X^{-1}\leftrightarrow\log\det(-Y)^{-1}-n\) on \(-\mathbf S^{n}_{++}\).

D6Traps

Dual vs primal norm — use the dual. Dropping the simplex from the log-sum-exp conjugate. The sign of the entropy: \(+\sum y_i\log y_i\). The intercept is \(\big(0,-f^{*}(y)\big)\), not \(\big(0,f^{*}(y)\big)\). Finite ≠ attained.

Main points for quick review

Definition (3.18)

\(f^{*}(y)=\sup_{x\in\operatorname{dom}f}(y^{\mathsf T}x-f(x))\); \(\operatorname{dom}f^{*}\) = where the sup is finite.

Always convex

Pointwise supremum of affine-in-\(y\) functions ⇒ convex whether or not \(f\) is.

Geometry (Fig 3.8)

\(f^{*}(y)\) = max gap between \(yx\) and \(f(x)\); the line \(yx-f^{*}(y)\) lies below \(f\), intercept \((0,-f^{*}(y))\), supports only when the sup is attained.

Recipe

Boundedness / direction ⇒ \(\operatorname{dom}f^{*}\); stationarity \(y=\nabla f(x)\) for smooth attained cases, other tools otherwise.

Scalar table (Ex 3.21)

\(ax+b\to-b\) on \(\{a\}\); \(-\log x\to-\log(-y)-1\); \(e^{x}\to y\log y-y\); \(x\log x\to e^{y-1}\); \(1/x\to-2(-y)^{1/2}\).
